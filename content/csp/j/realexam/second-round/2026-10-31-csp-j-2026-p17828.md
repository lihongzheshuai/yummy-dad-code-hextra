CSP-J 2026 第二轮入门组第二题《回文串》（`luogu-P17828`），给出由 $n$ 段连续相同字符组成的超长字符串（总长可达 $2\times 10^{14}$），要求计算将其修改为回文串所需的最少字符修改次数。本题核心考查**游程编码（RLE）压缩表示下的双指针同步消去技巧**，适合 GESP 四级与五级考生练习，难度 ⭐⭐☆☆☆，洛谷难度等级 `普及−`。

## P17828 [CSP-J 2026] 回文串 / string

> 🔗 **洛谷原题传送门**：[luogu-P17828 [CSP-J 2026] 回文串 / string](https://www.luogu.com.cn/problem/P17828)

### 题目要求

#### 题目描述

小 R 有一个长度为 $L$ 的字符串 $S=s_1\ldots s_L$，其中只包含小写英文字母。小 R 发现，虽然 $S$ 可能很长，但它可以分成 $n$ 个连续的段，其中第 $i\ (1\le i\le n)$ 段由 $a_i$ 个小写英文字母 $c_i$ 构成。把这 $n$ 段依次拼接起来便得到 $S$，因此 $L=\sum_{i=1}^{n}a_i$。相邻两段中的字符可以相同。

小 X 喜欢回文串。若一个字符串反转后与原字符串相同，就称它是回文串，例如 `aba`、`abba` 都是回文串，而 `aabbc` 不是。也就是说，字符串 $S$ 是回文串，当且仅当对于所有 $i\ (1\le i\le L)$，均有 $s_i=s_{L+1-i}$。

小 X 想让小 R 把 $S$ 改成回文串。小 R 可以将 $S$ 中任意一个位置的字符修改成任意小写英文字母。他想用尽量少的修改满足小 X 的要求。

你需要帮助小 R 求出，他最少需要修改多少个位置的字符，才能将 $S$ 改成回文串。

#### 输入格式

输入的第一行包含一个正整数 $n$。

输入的第 $i+1\ (1\le i\le n)$ 行包含一个正整数 $a_i$ 和一个小写英文字母 $c_i$。

#### 输出格式

输出一行一个整数，表示小 R 最少需要修改多少个位置的字符，才能将 $S$ 改成回文串。

#### 输入输出样例

##### 输入 #1
```text
3
2 a
2 b
1 c
```
##### 输出 #1
```text
2
```

##### 输入 #2
```text
2
2 a
3 a
```
##### 输出 #2
```text
0
```

##### 输入 #3
```text
6
1000000000 a
1000000000 a
1000000000 a
1000000000 b
1000000000 b
1000000000 b
```
##### 输出 #3
```text
3000000000
```

#### 说明/提示

##### 【样例 1 解释】
小 R 的字符串 $S$ 由 $3$ 段构成：第 $1$ 段由 $2$ 个 `a` 组成，第 $2$ 段由 $2$ 个 `b` 组成，第 $3$ 段由 $1$ 个 `c` 组成，依次拼接得到 $S=\mathtt{aabbc}$。
小 R 可以将最后一个字符 `c` 和倒数第二个字符 `b` 都改为 `a`，得到回文串 `aabaa`，共修改 $2$ 个位置的字符。可以证明，小 R 最少需要修改 $2$ 个位置的字符，才能将 $S$ 改成回文串。

##### 【样例 2 解释】
小 R 的字符串 $S$ 由 $2$ 段构成：第 $1$ 段由 $2$ 个 `a` 组成，第 $2$ 段由 $3$ 个 `a` 组成，依次拼接得到 $S=\mathtt{aaaaa}$，则 $S$ 已经是回文串，不需要修改。

##### 【数据范围】
对于所有测试数据，均有：
- $1\le n\le 2\times10^5$；
- 对于所有 $i\ (1\le i\le n)$，均有 $1\le a_i\le10^9$，且 $c_i$ 为小写英文字母。

| 测试点编号 | $n\le$ | $\max_{i=1}^{n}a_i\le$ |
| :-: | :-: | :-: |
| $1$ | $1$ | $5$ |
| $2\sim4$ | $2$ | $5$ |
| $5,6$ | $10$ | $1$ |
| $7,8$ | $10$ | $50$ |
| $9$ | $2000$ | $1$ |
| $10\sim12$ | $2000$ | $50$ |

| $17,18$ | $2\times10^5$ | $1$ |
| $19\sim21$ | $2\times10^5$ | $500$ |

### 题目分析

#### 1. 基本性质：回文修改的独立性
对于长度为 $L$ 的字符串 $S$，回文条件要求每一对对称位置 $(i, L+1-i)$ 满足 $s_i = s_{L+1-i}$。
- 如果 $s_i = s_{L+1-i}$，这一对字符不用修改；
- 如果 $s_i \ne s_{L+1-i}$，只需把其中一个改成另一个（修改 $1$ 次），就能使这一对相等。
因此，**最少修改次数就等于前半部分与后半部分对应位置字符不相等的对数**。

#### 2. 为什么不能直接展开字符串？
观察数据范围：$n \le 2 \times 10^5$，每段长度 $a_i \le 10^9$，字符串总长 $L$ 最大可达 $2 \times 10^{14}$！如果直接拼接出原字符串 $S$，内存和时间都会彻底爆炸（最多只能拿到 $a_i \le 500$ 的部分分）。

#### 3. 满分正解：在连续段上直接做双指针对齐消去
既然字符串是按“段”给出的，第 $l$ 段有 $a_l$ 个字符 $c_l$，第 $r$ 段有 $a_r$ 个字符 $c_r$，我们完全可以用**双指针** `l = 1` 和 `r = n` 分别指向当前最左段和最右段：
1. 当 `l < r` 时，左端有 $a_l$ 个连续的 $c_l$，右端有 $a_r$ 个连续的 $c_r$。它们在首尾对称位置上能够**成批对齐匹配**的长度为：
   $$\text{take} = \min(a_l, a_r)$$
2. 如果 $c_l \ne c_r$，这 $\text{take}$ 对字符全部不相等，答案累加 `ans += take`；如果 $c_l = c_r$，则这 $\text{take}$ 对字符天然相等，无需修改。
3. 随后将两端各自的剩余长度减去 $\text{take}$：
   - `a[l] -= take`，若 `a[l] == 0`，说明左端第 $l$ 段已全部匹配完毕，指针右移 `l++`；
   - `a[r] -= take`，若 `a[r] == 0`，说明右端第 $r$ 段已全部匹配完毕，指针左移 `r--`。
4. 当循环进行到 `l == r` 时，说明只剩下最中间的同一段字符（全都是字符 $c_l$），它跟自己反转对称必然全部相等，无需任何修改，直接结束循环！

#### 4. 复杂度与十年OI一场空提醒
- **时间复杂度**：每次 `while (l < r)` 循环至少会将 `a[l]` 或 `a[r]` 中的一个减为 $0$ 并移动指针，因此最多执行 $n$ 次迭代，时间复杂度为严格的 $O(n)$。
- **数据类型陷阱**：由于 $a_i \le 10^9$，最终答案 `ans` 最大可达 $10^{14}$ 量级（如样例 3 输出 `3000000000` 已经超过 32 位 `int` 上限 $2.14\times 10^9$），因此 **`a[i]`、`take` 和 `ans` 必须全部定义为 `long long`**！

### 示例代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// P17828 [CSP-J 2026] 回文串 (string)
// 游程编码 (Run-Length Encoding) 上的双指针模拟
const int MAXN = 200005;
long long a[MAXN];
char c[MAXN];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i] >> c[i];
    }

    int l = 1, r = n;
    long long ans = 0;

    // 从字符串首尾两端同时向中间对齐消去
    while (l < r) {
        long long take = min(a[l], a[r]);
        if (c[l] != c[r]) {
            ans += take;
        }
        a[l] -= take;
        a[r] -= take;
        if (a[l] == 0) {
            l++;
        }
        if (a[r] == 0) {
            r--;
        }
    }

    cout << ans << endl;
    return 0;
}
```
