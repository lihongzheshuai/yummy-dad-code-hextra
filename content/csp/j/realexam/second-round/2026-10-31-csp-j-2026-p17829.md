## P17829 [CSP-J 2026] 按位与 / and

### 题目要求

#### 题目描述

> 小 R 有 $n$ 个非负整数 $a_1,a_2,\ldots,a_n$。
>
> 小 X 给了小 R 一个正整数 $m$，并要求小 R 从这 $n$ 个非负整数中选出**恰好** $m$ 个，使得选出的 $m$ 个数的**二进制按位与**的值最大。
>
> 你需要帮助小 R 求出，他能选出的 $m$ 个数的按位与的最大值。

#### 输入格式

> 输入的第一行包含两个正整数 $n,m$。
>
> 输入的第二行包含 $n$ 个非负整数 $a_1,a_2,\ldots,a_n$，依次表示小 R 的 $n$ 个非负整数。

#### 输出格式

> 输出一行一个非负整数，表示小 R 能选出的 $m$ 个数的按位与的最大值。

#### 输入输出样例

##### 输入 #1
```text
4 2
3 15 12 12
```
##### 输出 #1
```text
12
```

##### 输入 #2
```text
5 3
31 3 1 15 7
```
##### 输出 #2
```text
7
```

#### 说明/提示

##### 【样例 1 解释】
小 R 有 $4$ 个非负整数：$3,15,12,12$。
- 若小 R 选择 $3,15$，则按位与的值为 $3\mathbin{\mathrm{and}}15=3$；
- 若小 R 选择 $3,12$，则按位与的值为 $3\mathbin{\mathrm{and}}12=0$；
- 若小 R 选择 $15,12$，则按位与的值为 $15\mathbin{\mathrm{and}}12=12$；
- 若小 R 选择 $12,12$，则按位与的值为 $12\mathbin{\mathrm{and}}12=12$。

因此，小 R 能选出的 $m$ 个数的按位与的最大值为 $12$。

##### 【样例 2 解释】
若小 R 选择 $31,15,7$，则按位与的值为 $31\mathbin{\mathrm{and}}15\mathbin{\mathrm{and}}7=7$。可以证明，小 R 能选出的 $m$ 个数的按位与的最大值为 $7$。

##### 【数据范围】
对于所有测试数据，均有：
- $1\le m\le n\le 2\times 10^5$；
- 对于所有 $i$（$1\le i\le n$），均有 $0\le a_i<2^{30}$。

### 题目分析

#### 1. 核心观察：按位与（`&`）与二进制高位的绝对统治力
在二进制中，两个整数比较大小，取决于它们从高到低第一个不同的二进制位。因为：
$$2^k > 2^{k-1} + 2^{k-2} + \dots + 2^0 = 2^k - 1$$
也就是说，**只要高位的某一个二进制位能变成 `1`，哪怕它后面的所有低位全部变成 `0`，最终的数值也一定比该高位为 `0` 时更大**！

同时，根据按位与（`&`）的运算规则：选出的 $m$ 个数按位与的结果在某一位上为 `1`，**当且仅当这 $m$ 个数在该二进制位上全部为 `1`**。

#### 2. 从高位到低位逐位试填贪心算法
由于题目中 $0 \le a_i < 2^{30}$，每个数的二进制最高位不超过第 $29$ 位（从 $0$ 开始编号）。
我们可以用一个变量 `ans`（初始为 `0`）记录当前已经锁定必须为 `1` 的二进制位掩码，然后从 `bit = 29` 递减枚举到 `bit = 0`：
1. **构造试填目标**：假设在已锁定高位 `ans` 的基础上，我们还希望第 `bit` 位也为 `1`，则候选数必须满足的掩码为：
   $$\text{target} = \text{ans} \mid (1 \ll \text{bit})$$
2. **检验可行性**：遍历数组 $a_1 \dots a_n$，统计有多少个数包含 `target` 中的所有 `1` 位——即满足 `(a[i] & target) == target` 的元素个数 `cnt`。
3. **贪心决策**：
   - 若 `cnt >= m`：说明原数组中至少有 $m$ 个数同时拥有 `target` 的全部 `1` 位！第 `bit` 位完全可以取 `1`，于是正式锁定该位：更新 `ans = target`；
   - 若 `cnt < m`：说明在保留更高位最优结果的前提下，凑不够 $m$ 个数让第 `bit` 位也为 `1`，因此第 `bit` 位只能放弃（保持为 `0`），`ans` 不变。

#### 3. 复杂度分析
- 外层循环固定枚举 $30$ 个二进制位（$29 \to 0$），内层循环扫描 $n$ 个元素；
- 总时间复杂度为 $O(30n)$，当 $n = 2 \times 10^5$ 时仅需 $6 \times 10^6$ 次基本位运算，运行时间不足 `0.02s`，空间复杂度 $O(n)$，轻松拿满 $100$ 分。

### 示例代码

```cpp
#include <iostream>
using namespace std;

// P17829 [CSP-J 2026] 按位与 (and)
// 按二进制位从高到低贪心构造最优掩码
const int MAXN = 200005;
int a[MAXN];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    int ans = 0;
    // a_i < 2^30，最高二进制位为第 29 位，从高位到低位依次试填 1
    for (int bit = 29; bit >= 0; bit--) {
        int target = ans | (1 << bit);
        int cnt = 0;
        for (int i = 1; i <= n; i++) {
            if ((a[i] & target) == target) {
                cnt++;
            }
        }
        // 若至少有 m 个数同时具备 target 的所有二进制 1 位，则该位可以置 1
        if (cnt >= m) {
            ans = target;
        }
    }

    cout << ans << endl;
    return 0;
}
```
