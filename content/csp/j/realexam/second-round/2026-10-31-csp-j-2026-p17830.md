## P17830 [CSP-J 2026] 纸牌游戏 / card

> 🔗 **洛谷原题传送门**：[luogu-P17830 [CSP-J 2026] 纸牌游戏 / card](https://www.luogu.com.cn/problem/P17830)

### 题目要求

#### 题目描述

小 Z 正在玩一种单人纸牌游戏。

他有一叠特制的纸牌，共有 $n$ 张，从上到下的点数依次为 $a_1,a_2,\ldots,a_n$。每张牌的点数都是 $1$ 到 $m$ 之间的整数，且每种点数都出现至少一次。

小 Z 将进行 $n$ 局相互独立的游戏。每局开始前，他会将所有牌按原顺序放回牌堆，并清空桌面。在第 $i$（$1\le i\le n$）局中，他跳过前 $i-1$ 张牌，依次打出第 $i$ 张到第 $n$ 张牌，这些牌的点数依次为 $a_i,a_{i+1},\ldots,a_n$。

桌面上的牌始终从左到右排成一行。打出一张点数为 $k$ 的牌时：
- 若桌面上没有点数为 $k$ 的牌，就将这张牌放在最右端；
- 否则，收走桌面上点数为 $k$ 的牌及其右侧的所有牌，再把这张牌放在最右端。被收走的牌在本局中不再使用。

由上述规则可知，任意时刻桌面上同一种点数的牌至多只有一张。

最后一张牌打出后，本局游戏结束。

例如，若桌面上从左到右的牌的点数依次为 $1,4,2$，则打出一张点数为 $3$ 的牌后，桌面上从左到右的牌的点数依次为 $1,4,2,3$。接着打出一张点数为 $4$ 的牌时，桌面上原来点数为 $4$ 的牌及其右侧的所有牌（点数依次为 $4,2,3$）被收走，再把新打出的 $4$ 放在最右端，此时桌面上从左到右的牌的点数依次为 $1,4$。

你需要帮助小 Z 依次求出，对于每个 $i=1,2,\ldots,m$，在所有 $n$ 局游戏中，有多少局结束时桌面上留有点数为 $i$ 的牌。

#### 输入格式

输入的第一行包含两个正整数 $n,m$，分别表示牌的数量和点数种类数。

输入的第二行包含 $n$ 个正整数 $a_1,a_2,\ldots,a_n$，依次表示小 Z 的牌从上到下的点数。

#### 输出格式

输出一行 $m$ 个非负整数，其中第 $i$（$1\le i\le m$）个整数表示在所有 $n$ 局游戏中，有多少局结束时桌面上留有点数为 $i$ 的牌。

#### 输入输出样例

##### 输入 #1
```text
4 3
1 2 1 3
```
##### 输出 #1
```text
3 1 4
```

##### 输入 #2
```text
10 3
3 1 2 1 3 2 3 1 2 1
```
##### 输出 #2
```text
10 3 3
```

#### 说明/提示

##### 【样例 1 解释】
对于第 $1$ 局游戏，小 Z 依次打出点数为 $1,2,1,3$ 的牌：
1. 打出第 $1$ 张牌（点数为 $1$）后，桌面上只有一张点数为 $1$ 的牌；
2. 打出第 $2$ 张牌（点数为 $2$）后，桌面上从左到右的牌的点数依次为 $1,2$；
3. 打出第 $3$ 张牌（点数为 $1$）后，先收走桌面上点数为 $1,2$ 的两张牌，再放上新打出的 $1$，桌面上只有一张点数为 $1$ 的牌；
4. 打出第 $4$ 张牌（点数为 $3$）后，桌面上从左到右的牌的点数依次为 $1,3$。

因此第 $1$ 局游戏结束时，桌面上从左到右的牌的点数依次为 $1,3$。
- 对于第 $2$ 局游戏，小 Z 依次打出点数为 $2,1,3$ 的牌，结束时桌面上从左到右的牌的点数依次为 $2,1,3$。
- 对于第 $3$ 局游戏，小 Z 依次打出点数为 $1,3$ 的牌，结束时桌面上从左到右的牌的点数依次为 $1,3$。
- 对于第 $4$ 局游戏，小 Z 仅打出一张点数为 $3$ 的牌，结束时桌面上只有一张点数为 $3$ 的牌。

因此，在全部 $4$ 局游戏中：
- 有 $3$ 局游戏结束时，桌面上留有点数为 $1$ 的牌，即第 $1,2,3$ 局；
- 有 $1$ 局游戏结束时，桌面上留有点数为 $2$ 的牌，即第 $2$ 局；
- 有 $4$ 局游戏结束时，桌面上留有点数为 $3$ 的牌，即全部 $4$ 局。

##### 【数据范围】
对于所有测试数据，均有：
- $2\le n\le 5\times 10^5$，$1\le m\le 3\times 10^5$；
- 对于所有 $i$（$1\le i\le n$），均有 $1\le a_i\le m$；
- 每种点数都出现至少一次，即对于所有 $i$（$1\le i\le m$），均存在 $j$（$1\le j\le n$）满足 $a_j=i$。

| 测试点编号 | $n\le$ | $m\le$ | 特殊性质 |
| :---: | :---: | :---: | :---: |
| $1\sim 3$ | $5$ | $2$ | 无 |
| $4\sim 6$ | $500$ | $200$ | 无 |
| $7\sim 9$ | $5000$ | $3000$ | A |
| $10\sim 12$ | $5000$ | $3000$ | 无 |
| $13,14$ | $2\times 10^5$ | $2$ | 无 |
| $15\sim 17$ | $2\times 10^5$ | $3000$ | B |
| $18,19$ | $2\times 10^5$ | $3000$ | 无 |
| $20$ | $2\times 10^5$ | $10^5$ | A |
| $21,22$ | $2\times 10^5$ | $10^5$ | 无 |
| $23\sim 25$ | $5\times 10^5$ | $3\times 10^5$ | 无 |

- 特殊性质 A：$a_1\le a_2\le\cdots\le a_n$。
- 特殊性质 B：至多存在 $4999$ 个 $i$（$1\le i\le n-1$）满足 $a_i\ne a_{i+1}$。

### 题目分析

如果直接对每一局游戏从 $i$ 到 $n$ 暴力模拟，时间复杂度为 $O(n^2)$，只能通过 $n \le 5000$ 的前 $12$ 个测试点（$48$ 分）。要拿下 $n \le 5 \times 10^5$ 的满分，我们需要抓住桌面变化的**核心不变量**。

#### 1. 关键洞察：每局游戏打出的第一张牌 $a_i$ 会发生什么？
考虑第 $i$ 局游戏（依次打出 $a_i, a_{i+1}, \dots, a_n$）：
1. 游戏一开始，首先打出 $a_i$，此时桌面上只有 `[a_i]`，它位于桌面的**最左端（第 1 个位置）**。
2. 在后续出牌过程中，一张牌为什么会从桌面上彻底消失？**只有当它左边某张牌再次被打出时，它才会被连带收走**。
3. 但是，**$a_i$ 位于桌面的最左端，它的左边没有任何牌！** 因此：
   - 无论后面打出什么其他点数的牌，最多只能在 $a_i$ 的右边增删，永远不可能把最左端的 $a_i$ 消掉；
   - 而每当后面再次打出点数为 $a_i$ 的牌时，规则是“收走桌面上原有的 $a_i$ 及其右侧所有牌，再把新的 $a_i$ 放上去”——这相当于**把 $a_i$ 右侧积攒的所有牌一键清空，桌面上再次只剩下 `[a_i]` 一张牌**！

#### 2. 状态递推方程：跳向最后一次出现的位置
由上面的分析可以得出一个极其漂亮的结论：
设点数 $x$ 在整个序列 $a_1 \dots a_n$ 中**最后一次出现的位置**为 $\text{last\_pos}[x]$（显然对于 $x = a_i$，必有 $\text{last\_pos}[a_i] \ge i$）。
- 在第 $i$ 局游戏中，当进行到第 $p = \text{last\_pos}[a_i]$ 张牌时，打出的恰好是最后一张 $a_i$。此时桌面被清空重置为仅剩一张 `[a_i]`！
- 在 $p$ 之后（即从第 $p + 1$ 张牌到第 $n$ 张牌），序列中**再也不会出现 $a_i$**。这意味着最左端的 $a_i$ 再也不会被触发，而它在右侧接着摆出的牌，**与直接从第 $p + 1$ 张牌开局（第 $p + 1$ 局游戏）最终留下的桌面完全一模一样**！

用 $S(i)$ 表示第 $i$ 局游戏结束时桌面上的纸牌序列（规定 $S(n+1) = \emptyset$），则有：
$$S(i) = [a_i] + S(\text{last\_pos}[a_i] + 1)$$
而且由于 $a_i$ 在 $[\text{last\_pos}[a_i] + 1, n]$ 中绝不再出现，$a_i$ 与 $S(\text{last\_pos}[a_i] + 1)$ 中的所有点数**互不重复**！

#### 3. 线性递推统计答案
既然每一局游戏 $i$ 的最终桌面序列，就是沿着转移链：
$$i \longrightarrow (\text{last\_pos}[a_i] + 1) \longrightarrow \cdots \longrightarrow (n + 1)$$
一路经过的所有起点位置上的牌 $a_u$ 的集合，我们只需要正向做一次线性 DP（计数传递）：
1. 预处理每个点数 $v$ 最后一次出现的下标 `last_pos[v]`；
2. 设 `cnt[i]` 表示有多少局游戏的转移链会经过状态 $i$。因为第 $1 \sim n$ 局各自从 $i$ 出发，初始时令 `cnt[1..n] = 1`；
3. 从 $i = 1$ 到 $n$ 依次遍历：
   - 状态 $i$ 会将点数 `val = a[i]` 留在所有经过状态 $i$ 的游戏桌面上，因此 `ans[val] += cnt[i]`；
   - 随后这 `cnt[i]` 局游戏全部跳转到下一个状态 `nxt = last_pos[val] + 1`。若 `nxt <= n`，则令 `cnt[nxt] += cnt[i]`。

#### 4. 复杂度分析
- **时间复杂度**：预处理 `last_pos` 耗时 $O(n)$，正向递推耗时 $O(n)$，输出耗时 $O(m)$，总时间复杂度为严格的 $O(n + m)$，对于 $n = 5 \times 10^5$ 仅需几毫秒！
- **空间复杂度**：仅需几个长度为 $n$ 的一维数组，空间复杂度 $O(n + m)$。

### 示例代码

```cpp
#include <iostream>
using namespace std;

// P17830 [CSP-J 2026] 纸牌游戏 (card)
// 核心算法：桌面最左端纸牌不变量洞察 + 跳向最后出现位置的 O(n) 线性状态递推 (DP)
// 关键性质：
// 1. 第 i 局打出的第一张牌 a[i] 位于桌面最左端（左边没有任何牌），因此永远不会被左侧的牌连带消除；
// 2. 每当后续再次打出点数 a[i] 时，都会把 a[i] 右侧的所有牌清空；
// 3. 当 a[i] 在全序列中最后一次出现的位置 p = last_pos[a[i]] 被打出时，桌面被重置为仅剩一张 [a[i]]；
// 4. 在位置 p 之后，点数 a[i] 绝不再出现，因此右侧后续留下的牌完全等价于第 (p + 1) 局游戏的最终桌面！

// 牌的总数 n 最大为 5 * 10^5
const int MAXN = 500005;

// a[i] 存储从上到下第 i 张牌的点数
int a[MAXN];

// last_pos[v] 记录点数 v 在整个纸牌序列 a[1..n] 中最后一次出现的下标位置
int last_pos[MAXN];

// cnt[i] 表示在全部 n 局游戏中，有多少局游戏的桌面状态递推链会经过起点状态 i
long long cnt[MAXN];

// ans[v] 统计最终有多少局游戏结束时，桌面上留有点数为 v 的纸牌
long long ans[MAXN];

int main() {
    // 读取纸牌总数 n 和点数种类数 m
    int n, m;
    cin >> n >> m;

    // 读取每张牌的点数，同时预处理每个点数最后一次出现的位置 last_pos
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        // 不断覆盖更新，循环结束时 last_pos[v] 即为点数 v 最后一次出现的下标
        last_pos[a[i]] = i;
        // 初始时，第 i 局游戏本身从位置 i 开局，因此每个位置 i 初始拥有 1 个游戏局起点
        cnt[i] = 1;
    }

    // 按照位置从左到右（1 -> n）正向线性递推，传递每局游戏的状态链：i -> (last_pos[a[i]] + 1)
    for (int i = 1; i <= n; i++) {
        // 当前状态 i 打出的首张牌点数为 val = a[i]
        int val = a[i];

        // 1. 统计贡献：
        //    所有经过状态 i 的 cnt[i] 局游戏，其最终桌面上一定永久保留这张最左端的牌 val
        //    且由于后续跳转到 last_pos[val] + 1 之后再无点数 val，不会发生重复计数
        ans[val] += cnt[i];

        // 2. 状态转移：
        //    当位置 last_pos[val] 的最后一张 val 打出后，桌面仅剩 [val]，
        //    随后的出牌过程完全等价于转入第 nxt = last_pos[val] + 1 局游戏的状态
        int nxt = last_pos[val] + 1;
        if (nxt <= n) {
            cnt[nxt] += cnt[i];
        }
    }

    // 依次输出点数 1 到 m 各自在多少局游戏结束时留在桌面上
    for (int i = 1; i <= m; i++) {
        cout << ans[i] << (i == m ? "" : " ");
    }
    cout << endl;

    return 0;
}
```
