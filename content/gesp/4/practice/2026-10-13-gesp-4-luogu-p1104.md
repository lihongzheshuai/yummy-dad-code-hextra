在信息学奥林匹克竞赛中，处理包含多维度关联信息的数据集合并对其进行有序化重组，是考查选手算法设计与数据建模能力的核心基石。洛谷 P1104「生日」作为考查多关键字排序的经典入门试题，完美契合 CCF GESP 四级（结构体建模、多关键字排序规则设计）与 CSP-J 普及组的入门要求。题目的核心需求是将学校 OI 组同学按照“年龄从大到小”进行排序，并在生日完全相同时按照“输入靠后者优先”的规则决出平局。本题不仅考验对日常生活中“年龄大意味着出生日期早”这一自然语义的逆向逻辑转换，更深入考察了如何利用 C++ 的 `struct`（结构体）对复合实体进行抽象封装，以及如何构造满足严格弱序（Strict Weak Ordering）的多级仲裁比较逻辑。题目在洛谷的官方难度评级为`普及−`。

## luogu-P1104 生日

> 🔗 **洛谷原题传送门**：[luogu-P1104 生日](https://www.luogu.com.cn/problem/P1104)

### 题目描述

cjf 君想调查学校 OI 组每个同学的生日，并按照年龄从大到小的顺序排序。但 cjf 君最近作业很多，没有时间，所以请你帮她排序。

### 输入格式

输入共有 $n+1$ 行，

第 $1$ 行为 OI 组总人数 $n$；

第 $2$ 行至第 $n+1$ 行分别是每人的姓名 $s$、出生年 $y$、月 $m$、日 $d$。

### 输出格式

输出共有 $n$ 行，即 $n$ 个年龄从大到小同学的姓名（如果有两个同学年龄相同，输入靠后的同学先输出）。

### 输入输出样例

#### 输入 #1
```text
3
Yangchu 1992 4 23
Qiujingya 1993 10 13
Luowen 1991 8 1
```

#### 输出 #1
```text
Luowen
Yangchu
Qiujingya
```

### 说明/提示

数据保证，$1 < n < 100$，$1 \le |s| < 20$。保证年月日实际存在，且年份 $\in [1960, 2020]$。

---

### 题目深度剖析与核心解题模型

#### 1. 核心模型与直觉转换：年龄与出生日期的逆向映射

本题初学者最容易掉入的思维误区是**将“年龄从大到小”错误理解为“年份、月份从大到小”**。
- **生活常识与数学映射**：一个人的年龄取决于当前时间与出生时间的差值。出生越早（年份数值越小、月份数值越小、日期数值越小），度过的时间越长，年龄就越大。
- **排序方向判定**：因此，要求“年龄从大到小”排序，反映在年月日数值上，必须是**升序排序（数值小的在前）**。例如 1991 年出生的同学年龄明显大于 1992 年出生的同学，故 1991 年的记录应当排在 1992 年之前。

---

#### 2. 平局决胜规则（Tie-breaker）与输入时序捕获

题目明确规定：**如果有两个同学年龄相同，输入靠后的同学先输出**。
- 所谓“年龄相同”，是指出生年、月、日三项属性完全一致。
- 很多初学者会试图通过直接使用 `std::stable_sort` 来保持相对顺序，但注意：标准库的稳定排序保持的是**原本输入在前的依然在前**；而题目明确要求**输入靠后的先输出（即输入次序的降序排列）**。
- **最佳实践**：最稳健、清晰的工程化做法是在结构体中额外引入一个字段 `id`，在依次读入数据时记录其输入的顺序编号（$1, 2, \dots, n$）。当两个同学的年月日全部相同时，直接依据 `id` 的大小进行仲裁，`id` 较大者排在前面。这样即使使用常规快速排序 `std::sort`，也能保证结果百分之百准确且确定。

---

#### 3. 结构体设计与严格弱序（Strict Weak Ordering）

在 C++ 中，面对多个属性绑定的数据对象，推荐使用 `struct` 进行结构化封装：

```cpp
struct Student {
    string name; // 姓名
    int year;    // 出生年
    int month;   // 出生月
    int day;     // 出生日
    int id;      // 输入序号（1 ~ n）
};
```

比较函数必须满足数学上的**严格弱序**规则：
1. **第一关键字**：年份 `year`。若年份不相等，年份小的排在前面（`a.year < b.year`）；
2. **第二关键字**：月份 `month`。若年份相同但月份不相等，月份小的排在前面（`a.month < b.month`）；
3. **第三关键字**：日期 `day`。若年月均相同但日期不相等，日期小的排在前面（`a.day < b.day`）；
4. **第四关键字**：输入序号 `id`。若年月日完全相同，输入靠后者优先，即序号大的排在前面（`a.id > b.id`）。

分层判断逻辑清晰，互斥返回，能够完全杜绝条件遗漏或出现相等时返回 `true` 导致破坏严格弱序的潜在 Bug。

---

#### 4. 复杂度分析

- **时间复杂度**：题目中 $1 < n < 100$。使用 `std::sort` 对包含 $n$ 个元素的向量进行多关键字排序，时间复杂度为 $\mathcal{O}(n \log n)$。在 $n = 100$ 的极限情况下，比较操作次数仅约数百次，耗时远小于 $1\text{ms}$，在 $1.00\text{s}$ 的时限下瞬间通过。
- **空间复杂度**：存储 $n$ 个学生的数据，空间开销为 $\mathcal{O}(n)$，内存占用不足 $10\text{KB}$，极其轻量，远低于 $128.00\text{MB}$ 的限制。

### C++ 标准规范源码

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

// 定义学生信息结构体，封装姓名、出生年月日及输入先后序号
struct Student {
    string name; // 同学姓名
    int year;    // 出生年
    int month;   // 出生月
    int day;     // 出生日
    int id;      // 输入序号（1-based，用于并列时确定先后次序）
};

// 自定义多关键字比较函数
// 比较逻辑优先级：
// 1. 年龄从大到小：出生越早年龄越大，因此年份小的优先排在前面；
// 2. 年份相同时，月份小的优先排在前面；
// 3. 月份相同时，日期小的优先排在前面；
// 4. 年月日均相同时，输入靠后的优先排在前面（即 id 较大的优先）。
bool compareStudent(const Student &a, const Student &b) {
    if (a.year != b.year) {
        return a.year < b.year;
    }
    if (a.month != b.month) {
        return a.month < b.month;
    }
    if (a.day != b.day) {
        return a.day < b.day;
    }
    return a.id > b.id;
}

int main() {
    int n;
    cin >> n;

    // 声明动态数组存储所有同学信息
    vector<Student> students(n);
    for (int i = 0; i < n; i++) {
        cin >> students[i].name >> students[i].year >> students[i].month >> students[i].day;
        students[i].id = i + 1; // 记录输入的先后次序（输入越晚 id 越大）
    }

    // 调用 STL 快速排序算法
    sort(students.begin(), students.end(), compareStudent);

    // 按照排好序的次序依次输出每位同学的姓名
    for (int i = 0; i < n; i++) {
        cout << students[i].name << "\n";
    }

    return 0;
}
```

### 常见避坑指南

1. **避免比较逻辑方向倒置**：切忌看到“年龄从大到小”就直接写 `a.year > b.year`。牢记年份小代表出生早、年龄大。
2. **切勿忽视输入次序的记录**：若两个同学完全同年同月同日生，题目明确要求输入靠后者先输出。必须显式记录输入序号并将其作为降序依据，不可依赖不可靠的默认排序行为。
3. **保持比较函数的严格弱序**：在手写比较函数时，对于两个完全相等的对象切忌返回 `true`（例如写成 `<=`），否则会导致未定义行为。严格使用 `<` 与 `>` 进行分层仲裁即可保证程序稳健运行。
