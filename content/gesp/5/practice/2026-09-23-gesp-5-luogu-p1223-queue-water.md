洛谷经典算法题 P1223「排队接水」，是算法竞赛与等级考试中**贪心算法（Greedy Algorithm）**与**微扰交换论证（Exchange Argument）**的入门与奠基典范。本题标准收录于 CCF GESP 五级考纲（基础贪心算法核心考点）以及 CSP-J 普及组基础题单。题目核心考查如何将“使得所有人的平均等待时间最小”这一最优化目标，转化为“单人耗时对后续群体产生累积等待代价”的数学模型，通过高等数学中的**排序不等式（Rearrangement Inequality）**与微扰交换法严格证明其贪心选择性质，并结合结构体双关键字排序在 $\mathcal{O}(n \log n)$ 时间内完成求解。题目难度⭐⭐★☆☆，洛谷官方难度评级为`普及-`。

## luogu-P1223 排队接水

> 🔗 **洛谷原题传送门**：[luogu-P1223 排队接水](https://www.luogu.com.cn/problem/P1223)

### 题目描述

有 $n$ 个人在一个水龙头前排队接水，假如每个人接水的时间为 $T_i$，请编程找出这 $n$ 个人排队的一种顺序，使得 $n$ 个人的平均等待时间最小。


### 输入格式

第一行为一个整数 $n$。

第二行 $n$ 个整数，第 $i$ 个整数 $T_i$ 表示第 $i$ 个人的等待时间 $T_i$。


### 输出格式

输出文件有两行，第一行为一种平均时间最短的排队顺序；第二行为这种排列方案下的平均等待时间（输出结果精确到小数点后两位）。

### 输入输出样例

#### 输入 #1

```text
10 
56 12 1 99 1000 234 33 55 99 812
```

#### 输出 #1

```text
3 2 7 8 1 4 9 6 10 5
291.90
```

### 说明/提示

$n \leq 1000,t_i \leq 10^6$，不保证 $t_i$ 不重复。

当 $t_i$ 重复时，按照输入顺序即可（sort 是可以的）

### 题目深度剖析

#### 1. 核心数学模型与总等待时间公式展开

要最小化 $n$ 个人的平均等待时间，由于人数 $n$ 是固定的正整数，**最小化平均等待时间完全等价于最小化这 $n$ 个人的总等待时间**。

我们定义排列 $p = (p_1, p_2, \dots, p_n)$ 表示这 $n$ 个人最终的排队顺序（其中 $p_i$ 表示排在第 $i$ 位的人的原始编号），其对应的接水时间为 $T_{p_i}$。

根据题意，每个人的等待时间**不包括自己接水的时间**，只计算排在他前面的所有人接水所消耗的时间总和：
- 排在第 $1$ 位的人（$p_1$）：等待时间为 $0$；
- 排在第 $2$ 位的人（$p_2$）：等待时间为 $T_{p_1}$；
- 排在第 $3$ 位的人（$p_3$）：等待时间为 $T_{p_1} + T_{p_2}$；
- ……
- 排在第 $i$ 位的人（$p_i$）：等待时间为 $\sum_{j=1}^{i-1} T_{p_j}$。

现在，我们换一个视角，从**“每个人的接水时间被后续多少人等待”**这一贡献度角度进行重新聚类统计：
- 第 $1$ 位的人接水耗时 $T_{p_1}$，排在他后面的 $n-1$ 个人都必须等待他，因此 $T_{p_1}$ 对总等待时间的贡献为 $T_{p_1} \times (n-1)$；
- 第 $2$ 位的人接水耗时 $T_{p_2}$，排在他后面的 $n-2$ 个人等待他，贡献为 $T_{p_2} \times (n-2)$；
- 一般地，排在第 $i$ 位的人接水耗时 $T_{p_i}$，排在他后面的 $n-i$ 个人都要等待他，因此贡献为 $T_{p_i} \times (n-i)$；
- 排在最后一位（第 $n$ 位）的人接水耗时 $T_{p_n}$，后面没有任何人等待，贡献为 $T_{p_n} \times 0 = 0$。

由此，全部 $n$ 个人的总等待时间公式可以精确展开为：
$$\text{Total Wait Time} = \sum_{i=1}^n T_{p_i} \times (n - i) = T_{p_1}(n-1) + T_{p_2}(n-2) + \dots + T_{p_{n-1}}(1) + T_{p_n}(0)$$

#### 2. 贪心策略与微扰法（相邻交换法）严格证明

直观上，系数 $(n-i)$ 随排队位置 $i$ 的后移而严格递减。为了让总乘积和最小，我们直觉上应该**让接水时间短的人排在前面，接水时间长的人排在后面**。这就是本题的核心贪心策略。

为什么这种局部贪心策略必然能保证全局最优？我们可以利用算法证明中最经典的**微扰法（相邻交换论证法，Exchange Argument）**给出无懈可击的证明：

1. **假设反例**：假设存在某一个全局最优的排队方案 $p$，在其中存在相邻的两个人排在第 $k$ 位和第 $k+1$ 位，他们的接水时间满足逆序：
   $$T_{p_k} > T_{p_{k+1}}$$
2. **局部交换**：我们保持除第 $k$ 位和第 $k+1$ 位之外的所有人的位置不变，仅交换 $p_k$ 与 $p_{k+1}$ 的排队顺序，得到新的排队方案 $p'$。
3. **考察总等待时间的变化量 $\Delta$**：
   - 对于排在第 $1 \dots k-1$ 位的人：由于前面的队伍完全没有变动，他们的等待时间保持不变；
   - 对于排在第 $k+2 \dots n$ 位的人：他们需要等待前面所有人的时间之和为 $(T_{p_1} + \dots + T_{p_k} + T_{p_{k+1}} + \dots)$。由于加法满足交换律，交换 $p_k$ 与 $p_{k+1}$ 后前 $k+1$ 个人的总耗时完全不变，因此排在第 $k+2$ 位及以后的所有人等待时间也分秒不差；
   - 唯一受到影响的只有处于微扰局部之中的两个人：
     - 交换前：$p_{k+1}$ 需要等待 $p_k$，等待代价包含 $T_{p_k}$；
     - 交换后：$p_k$ 需要等待 $p_{k+1}$，等待代价变为 $T_{p_{k+1}}$。
   - 因此，交换后的总等待时间与交换前的差值为：
     $$\Delta = \text{Cost}(p') - \text{Cost}(p) = T_{p_{k+1}} - T_{p_k}$$
   - 因为我们假设了 $T_{p_k} > T_{p_{k+1}}$，所以必然有：
     $$\Delta < 0 \implies \text{Cost}(p') < \text{Cost}(p)$$
4. **推导矛盾**：交换后得到的新排队方案的总等待时间严格小于原本假定的“最优方案”，这与方案 $p$ 的最优性直接矛盾！
5. **结论成立**：最优排队方案中绝不可能存在任何相邻的逆序对。因此，所有人员必须严格按照接水时间单调不减（升序）排队：
   $$T_{p_1} \le T_{p_2} \le \dots \le T_{p_n}$$

#### 3. 排序不等式（Rearrangement Inequality）高观点视角

在高等数学与奥林匹克数学中，本题是**排序不等式**在计算机科学中的标准具象化应用。

设有两个长度为 $n$ 的实数序列：
- 序列 $A$ 为接水时间集合，从小到大排序为：$a_1 \le a_2 \le \dots \le a_n$；
- 序列 $B$ 为排队权重系数集合，从小到大排序为：$b_1 \le b_2 \le \dots \le b_n$（在本题中权重对应 $0, 1, 2, \dots, n-1$）。

排序不等式定理指出：
$$\sum_{i=1}^n a_i b_{n-i+1} \le \sum_{i=1}^n a_i b_{\pi(i)} \le \sum_{i=1}^n a_i b_i$$
即：**反序和 $\le$ 乱序和 $\le$ 顺序和**。

在本题中，总等待时间是接水时间与排队权重系数的内积。要想使总等待时间达到全局最小值，必须让两个序列按照**反序相配**：
- 权重最大的一项（即 $n-1$，代表被后续所有人等待），必须分配给接水时间最小的元素 $a_1$；
- 权重次大的一项（即 $n-2$），分配给接水时间次小的元素 $a_2$；
- ……
- 权重最小的一项（即 $0$，代表排在最后无人等待），分配给接水时间最大的元素 $a_n$。

这就从代数对称性与极值原理的最高维度，完全确立了按接水时间升序排序的必然性。

#### 4. 易错点与边界防坑指南

1. **整型溢出风险（高频失分点）**：
   - 题目数据范围：$n \le 1000$，$t_i \le 10^6$。
   - 最坏情况下（所有人接水时间均为 $10^6$），总等待时间可达：
     $$\text{Total} \approx \frac{1000 \times 999}{2} \times 10^6 \approx 4.995 \times 10^{11}$$
   - 32 位有符号整型 `int` 的上限约为 $2.14 \times 10^9$，$4.995 \times 10^{11}$ 远超 `int` 范围！
   - 若使用 `int` 存储总等待时间，会导致严重的符号位溢出变为负数，最终输出错误的平均等待时间。因此，累加变量必须使用 `long long` 声明，且在乘法计算时将操作数显式提升为 `long long`。
2. **结构体双关键字排序与严格弱序（Strict Weak Ordering）**：
   - 题目要求输出接水顺序的**原始编号**（1 到 $n$）。排序会打乱原始输入顺序，因此必须使用结构体（`struct Person { int id, time; };`）将编号与耗时捆绑。
   - 洛谷原题说明提示：“当 $t_i$ 重复时，按照输入顺序即可”。
   - 在自定义比较函数 `cmp(a, b)` 时，如果时间不同按时间升序（`a.time < b.time`）；如果时间相同，按编号升序（`a.id < b.id` 作为 tie-breaker 保证编号小的优先）。
   - **千万注意**：比较操作符必须严格使用 `<`，绝不可写 `<=`。在 C++ STL 中，`std::sort` 要求比较谓词满足严格弱序，若返回 `<=` 会导致自身与自身比较为真（`cmp(x, x) == true`），引发排序算法越界崩溃（Segmentation Fault）。
3. **平均等待时间的浮点输出精度**：
   - 题目要求结果精确到小数点后两位。
   - 计算平均值时，除法 `(double)total_wait_time / n` 必须保证被除数转换为 `double`，否则两个整数相除会发生截断丢失精度。
   - 格式化输出使用 `<iomanip>` 中的 `cout << fixed << setprecision(2) << avg;` 即可轻松搞定。
4. **单人排队边界 ($n = 1$)**：
   - 当 $n = 1$ 时，唯一的人在水龙头前不需要等待任何前置人员，等待时间为 0，平均等待时间应正确输出 `0.00`。
   - 在我们的公式中，当 $i = 0$ 时权重为 $(1 - 1 - 0) = 0$，`total_wait_time` 结果为 $0$，逻辑自然兼容。

#### 5. 复杂度深入分析

- **时间复杂度**：
  - 读取数据耗时 $\mathcal{O}(n)$；
  - 对包含 $n$ 个元素的结构体数组调用 `std::sort`，基于内省排序（Introsort，混合快速排序、堆排序与插入排序），时间复杂度为 $\mathcal{O}(n \log n)$；
  - 线性遍历计算总耗时并输出耗时 $\mathcal{O}(n)$；
  - 整体时间复杂度严格为 $\mathcal{O}(n \log n)$。代入 $n = 1000$，$n \log_2 n \approx 1000 \times 10 = 10^4$ 次基本操作，在计算机 1 秒可执行 $10^8$ 次操作的算力下，耗时不到 $1\text{ms}$，秒级 AC。
- **空间复杂度**：
  - 仅需一个大小为 $n$ 的结构体数组或 `std::vector<Person>` 存储人员编号与耗时，额外空间复杂度为 $\mathcal{O}(n)$。在 $n = 1000$ 时仅占用不到 $16\text{KB}$ 内存，远低于洛谷常规 $128\text{MB}$ 空间限制。

### 完整参考代码 (C++11)

```cpp
/**
 * Problem: luogu-P1223 排队接水
 * Algorithm: 贪心算法 (Greedy) / 排序不等式 (Rearrangement Inequality) / 微扰法 (Exchange Argument)
 * Standard: C++11 (CCF GESP 官方大纲规范)
 * Author: OneCoder
 */

#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip>

using namespace std;

// 定义结构体存储每个人的编号与接水耗时
struct Person {
    int id;    // 原始输入编号 (1 到 n)
    int time;  // 接水所需时间 t_i
};

// 自定义比较函数：按照接水时间从小到大升序排序
// 若接水时间相同，则严格按照原始输入编号从小到大排序 (稳定 tie-breaker)
// 严格遵循严格弱序 (Strict Weak Ordering)，绝不使用 <=
bool cmp(const Person& a, const Person& b) {
    if (a.time != b.time) {
        return a.time < b.time;
    }
    return a.id < b.id;
}

int main() {
    int n;
    cin >> n;

    // 创建 vector 存储 n 个排队人员的信息
    vector<Person> p(n);
    for (int i = 0; i < n; ++i) {
        p[i].id = i + 1; // 记录 1-indexed 原始编号
        cin >> p[i].time;
    }

    // 贪心策略：接水时间短的人优先服务
    // 根据排序不等式与微扰交换法，接水时间升序排列可使全局总等待时间严格最小
    sort(p.begin(), p.end(), cmp);

    // 统计所有人的总等待时间
    // 第 i 个人（0-indexed）接水时，排在他后面的 (n - 1 - i) 个人都在等待他
    // 因此第 i 个人的接水时间对总等待时间的贡献为 p[i].time * (n - 1 - i)
    // 极限情况下 1000 * 1000 / 2 * 10^6 ≈ 5 * 10^11，超出 32 位整型范围，必须使用 long long
    long long total_wait_time = 0;

    // 输出最优排队顺序（人的编号，空格分隔）
    for (int i = 0; i < n; ++i) {
        cout << p[i].id << (i == n - 1 ? "" : " ");
        total_wait_time += (long long)p[i].time * (n - 1 - i);
    }
    cout << endl;

    // 计算平均等待时间并保留两位小数
    double avg_wait_time = (double)total_wait_time / n;
    cout << fixed << setprecision(2) << avg_wait_time << endl;

    return 0;
}
```
