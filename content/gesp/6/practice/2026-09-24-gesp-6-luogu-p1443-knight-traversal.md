洛谷经典算法题 P1443「马的遍历」，是算法竞赛与等级考试中**广度优先搜索（Breadth-First Search, BFS）**求解**无权图单源最短路**的奠基经典题。本题标准收录于 CCF GESP 六级考纲（搜索算法核心考点）以及 CSP-J 普及组核心训练题单。题目考查如何将中国象棋中“马走日”的规则抽象为二维网格图上的状态跃迁，结合先进先出（FIFO）的队列（`std::queue`）实现逐层水波纹扩展，在 $\mathcal{O}(nm)$ 时间复杂度内计算出从起点出发到达棋盘所有位置的最少步数。题目难度⭐⭐★☆☆，洛谷官方难度评级为`普及-`。

## luogu-P1443 马的遍历

> 🔗 **洛谷原题传送门**：[luogu-P1443 马的遍历](https://www.luogu.com.cn/problem/P1443)

### 题目描述

有一个 $n \times m$ 的棋盘，在某个点 $(x, y)$ 上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。


### 输入格式

输入只有一行四个整数，分别为 $n, m, x, y$。


### 输出格式

一个 $n \times m$ 的矩阵，代表马到达某个点最少要走几步（不能到达则输出 $-1$）。


### 输入输出样例

#### 输入 #1
```text
3 3 1 1
```

#### 输出 #1

```text
0    3    2    
3    -1   1    
2    1    4
```

### 说明/提示

#### 数据规模与约定

对于全部的测试点，保证 $1 \leq x \leq n \leq 400$，$1 \leq y \leq m \leq 400$。

2022 年 8 月之后，本题去除了对输出保留场宽的要求。为了与之兼容，本题的输出以空格或者合理的场宽分割每个整数都将判作正确。

### 题目深度剖析

#### 1. 核心模型：网格图无权单源最短路与广度优先搜索（BFS）

在图论与搜索算法中，若图中所有边的权重均相等（在本题中，马跳跃一次的步数权值恒为 $1$），要求从单一源点出发到达各顶点的**最少步数**，此问题属于经典的**无权图单源最短路径问题**。

求解无权图最短路，**广度优先搜索（BFS）是唯一具有严格理论保证的线性最优解法**：
- **水波纹扩展机制**：BFS 借助**先进先出（FIFO, First-In First-Out）**的队列数据结构，严格按照距离起点的步数由近及远、逐层向外扩散（层序遍历）。
- **最短路单调性定理**：在边权为 1 的图中，步数为 $d$ 的所有状态必然严格在步数为 $d+1$ 的状态之前全部出队并被处理完毕。因此，**任意网格点在全过程中第一次被访问到的时刻，记录下的步数必然就是到达该点的全局最少步数**。
- **与 DFS（深度优先搜索）的对比**：若使用深度优先搜索，程序会沿着某一条分支一路走到底，极易在无权网格图中产生大量的无效搜索与冗余回溯，不仅难以保证首次到达即为最优解，而且极易导致递归爆栈或运行超时（Time Limit Exceeded, TLE）。

#### 2. 状态定义与马的“日”字形八向跃迁

我们将马在棋盘上的状态抽象为一个二维坐标 $(x, y)$。

根据象棋规则，马跳一步的轨迹为“日”字形，即在某一坐标轴方向移动 $2$ 个单位，同时在垂直于它的坐标轴方向移动 $1$ 个单位。需要特别指出的是，本题属于纯网格图跳跃模型，**不存在中国象棋中“别马腿”（绊马脚）的阻挡规则**，因此在任意位置，马最多可以跳向 $8$ 个互不相同的相邻坐标：
- 向上跳：$(-2, -1)$、$(-2, +1)$
- 向下跳：$(+2, -1)$、$(+2, +1)$
- 向左跳：$(-1, -2)$、$(+1, -2)$
- 向右跳：$(-1, +2)$、$(+1, +2)$

在 C++ 程序设计中，我们通过定义常量增量方向向量数组 `dx[8]` 与 `dy[8]`，可以在循环体内优雅而高效地遍历全部 8 个方向，避免冗长且易错的连续 `if-else` 分支。

#### 3. 访问标记与状态去重（防成环与剪枝）

在网格图搜索中，马跳跃可能出现“A -> B -> A”的来回跳跃，若不加以记录，搜索过程将深陷无休止的死循环。

- **距离数组即访问标记**：我们声明全局数组 `dist[405][405]`，并在搜索开始前将棋盘内所有格子的距离统一初始化为 `-1`。
- **状态转移判定**：
  1. 起点 $(sx, sy)$ 距离初始化为 $0$：`dist[sx][sy] = 0`，并将起点推入队列；
  2. 当尝试拓展新坐标 $(nx, ny)$ 时，首先进行边界合法性检查：$1 \le nx \le n$ 且 $1 \le ny \le m$；
  3. 接着检查状态标记：只有当 `dist[nx][ny] == -1` 时，才表明该格子此前从未被波纹触达。此时立即更新距离：
     $$\text{dist}[nx][ny] = \text{dist}[cur.x][cur.y] + 1$$
     并将 $(nx, ny)$ 推入队列末尾；
  4. 若 `dist[nx][ny] != -1`，说明该点已被更早（步数更少或相等）的层级访问过，直接剪枝跳过。

由于每个格子在整个搜索生命周期中**至多只入队一次**，从根本上消除了重复运算与环路死锁。

#### 4. 易错点与边界防坑指南

1. **坐标系与 1-indexed 规范**：
   - 题目给定坐标满足 $1 \le x \le n$，$1 \le y \le m$。务必牢记行数为 $n$（对应横坐标 $x$），列数为 $m$（对应纵坐标 $y$）。
   - 越界判断条件必须严格写为：`nx >= 1 && nx <= n && ny >= 1 && ny <= m`，避免将 $n$ 和 $m$ 颠倒。
2. **不可达格子的自然处理**：
   - 棋盘上可能存在马无论如何也无法到达的格子（例如当 $n=3, m=3$ 且起点在 $(1, 1)$ 时，中心点 $(2, 2)$ 无法通过任何日字形跃迁到达）。
   - 由于我们预先将整个 `dist` 数组刷为 `-1`，未被 BFS 波纹覆盖的盲区点将自然保持为 `-1`，输出时无需编写任何特殊的特判逻辑。
3. **输出格式规范化**：
   - 洛谷官方已自 2022 年 8 月起全面放宽了对历史旧题保留 5 场宽（`setw(5)`）的严苛限制，采用行内以标准空格隔开的输出完全兼容判题系统。
   - 每行末尾输出换行符 `\n`，结构整洁规范。
4. **内存与静态数组安全**：
   - 题目规模为 $1 \le n, m \le 400$。定义全局静态数组大小为 $405 \times 405$，既留出充足的边界安全裕量，又完全杜绝了局部变量栈溢出风险。

#### 5. 复杂度深入分析

- **时间复杂度**：
  - 棋盘共有 $n \times m$ 个网格顶点；
  - 在 BFS 运行过程中，每个顶点至多入队一次、出队一次；
  - 每个顶点在出队展开时，仅尝试 $8$ 个常数级别的邻接方向，状态判定均为 $\mathcal{O}(1)$；
  - 因此整体时间复杂度严格为：
    $$\mathcal{O}(n \times m)$$
  - 代入极限数据规模 $n = 400, m = 400$，$n \times m = 1.6 \times 10^5$。总循环展开次数不超过 $1.6 \times 10^5 \times 8 \approx 1.28 \times 10^6$ 次操作。在现代计算机每秒约执行 $10^8$ 次基本运算的吞吐量下，实际耗时不到 $15\text{ms}$，秒级 AC。
- **空间复杂度**：
  - 全局静态矩阵 `dist[405][405]` 占用内存约 $405 \times 405 \times 4\text{ 字节} \approx 656\text{KB}$；
  - BFS 队列在最宽层级时存储的节点数量不会超过 $\mathcal{O}(nm)$，峰值内存占用小于 $2\text{MB}$；
  - 整体空间复杂度为 $\mathcal{O}(nm)$，远低于洛谷设定的 $128.00\text{MB}$ 内存上限。

### 完整参考代码 (C++11)

```cpp
/**
 * Problem: luogu-P1443 马的遍历
 * Algorithm: 广度优先搜索 (Breadth-First Search, BFS) / 网格图无权单源最短路
 * Standard: C++11 (CCF GESP 官方大纲规范)
 * Author: OneCoder
 */

#include <iostream>
#include <vector>
#include <queue>

using namespace std;

// 棋盘最大规模为 400 x 400，预留边界裕量
const int MAXN = 405;

// 马在棋盘上的 8 个移动方向（日字形跳跃）
// 组合分别为：(±2, ±1) 以及 (±1, ±2)
const int dx[8] = {-2, -2, -1, -1, 1, 1, 2, 2};
const int dy[8] = {-1, 1, -2, 2, -2, 2, -1, 1};

// 存储马到达棋盘各点的最少步数
// 全局初始化为 -1，兼具“距离存储”与“是否已访问判定”双重功能
int dist[MAXN][MAXN];

// 定义结构体表示棋盘上的坐标点
struct Point {
    int x; // 行坐标 (1 到 n)
    int y; // 列坐标 (1 到 m)
};

int main() {
    int n, m, sx, sy;
    cin >> n >> m >> sx >> sy;

    // 初始化整个棋盘的所有格子步数为 -1（表示未访问或不可达）
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            dist[i][j] = -1;
        }
    }

    // 声明广度优先搜索队列，管理待拓展的棋盘状态
    queue<Point> q;

    // 起点步数设为 0，并将起点坐标推入队列
    dist[sx][sy] = 0;
    Point start;
    start.x = sx;
    start.y = sy;
    q.push(start);

    // 开始 BFS 层次遍历
    while (!q.empty()) {
        Point cur = q.front();
        q.pop();

        // 尝试向 8 个日字形方向跳跃拓展
        for (int i = 0; i < 8; ++i) {
            int nx = cur.x + dx[i];
            int ny = cur.y + dy[i];

            // 1. 越界检查：确保新坐标处于 n x m 棋盘内部
            if (nx >= 1 && nx <= n && ny >= 1 && ny <= m) {
                // 2. 访问检查：若 dist 仍为 -1，说明此前从未被水波纹触及
                if (dist[nx][ny] == -1) {
                    // 记录到达新点的最少步数（当前点步数 + 1）
                    dist[nx][ny] = dist[cur.x][cur.y] + 1;
                    // 将新点加入队列，等待后续继续向外层拓展
                    Point next_point;
                    next_point.x = nx;
                    next_point.y = ny;
                    q.push(next_point);
                }
            }
        }
    }

    // 按照题目要求输出 n x m 的矩阵
    // 每个整数代表马到达该位置的最少步数（无法到达自然输出 -1）
    // 每行数字以空格分隔
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            cout << dist[i][j] << (j == m ? "" : " ");
        }
        cout << "\n";
    }

    return 0;
}
```
