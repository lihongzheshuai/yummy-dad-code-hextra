洛谷经典算法题 P1434「[SHOI2002] 滑雪」，是算法竞赛与等级考试中**记忆化搜索（Memoized Search）**与**有向无环图（DAG）动态规划**的开山之作与核心经典。本题标准收录于 CCF GESP 六级考纲（搜索与动态规划核心考点）以及 CSP-J 普及组核心进阶题单。题目要求在二维网格高度图中，寻找一条高度严格单调递减的最长路径。由于滑雪只能从高处向低处滑行，天然杜绝了环路的存在，构成隐式的网格有向无环图。通过将深度优先搜索（DFS）与动态规划记忆化数组（`memo`）深度融合，可将指数级暴搜复杂度骤降至严格的 $\mathcal{O}(RC)$ 线性时空，完美展示了“重叠子问题”与“最优子结构”的算法精髓。题目难度⭐⭐★☆☆，洛谷官方难度评级为`普及/提高-`。

## luogu-P1434 [SHOI2002] 滑雪

> 🔗 **洛谷原题传送门**：[luogu-P1434 [SHOI2002] 滑雪](https://www.luogu.com.cn/problem/P1434)

### 题目描述

Michael 喜欢滑雪。这并不奇怪，因为滑雪的确很刺激。可是为了获得速度，滑的区域必须向下倾斜，而且当你滑到坡底，你不得不再次走上坡或者等待升降机来载你。Michael 想知道在一个区域中最长的滑坡。区域由一个二维数组给出。数组的每个数字代表点的高度。下面是一个例子：

```plain
1   2   3   4   5
16  17  18  19  6
15  24  25  20  7
14  23  22  21  8
13  12  11  10  9
```

一个人可以从某个点滑向上下左右相邻四个点之一，当且仅当高度会减小。在上面的例子中，一条可行的滑坡为 $24-17-16-1$（从 $24$ 开始，在 $1$ 结束）。当然    $25$－$24$－$23$－$\ldots$－$3$－$2$－$1$ 更长。事实上，这是最长的一条。

### 输入格式

输入的第一行为表示区域的二维数组的行数 $R$ 和列数 $C$。下面是 $R$ 行，每行有 $C$ 个数，代表高度(两个数字之间用 $1$ 个空格间隔)。

### 输出格式

输出区域中最长滑坡的长度。

### 输入输出样例

#### 输入 #1

```text
5 5
1 2 3 4 5
16 17 18 19 6
15 24 25 20 7
14 23 22 21 8
13 12 11 10 9
```

#### 输出 #1

```text
25
```

### 说明/提示

对于 $100\%$ 的数据，$1\leq R,C\leq 100$。

对于任意输入的高度 $h$，满足 $0 \le h \le 10000$，且 $h$ 是整数。

---

### 题目深度剖析

#### 1. 核心模型：网格有向无环图（DAG）与最长路径

在图论视角下，我们可以将整个 $R \times C$ 网格抽象为一个有向图 $G = (V, E)$：
- **顶点集 $V$**：网格中的每个坐标点 $(x, y)$ 是图的一个顶点，顶点总数为 $|V| = R \times C$；
- **有向边集 $E$**：对于任意两个几何相邻（上下左右）的点 $u(x_1, y_1)$ 与 $v(x_2, y_2)$，当且仅当高度满足 $h(u) > h(v)$ 时，存在一条从 $u$ 指向 $v$ 的有向边 $(u, v)$，边权恒为 $1$。

**无环性证明（DAG 定理）**：
若图中存在环路 $v_1 \to v_2 \to \dots \to v_k \to v_1$，则沿此环遍历各点高度必然满足：
$$h(v_1) > h(v_2) > \dots > h(v_k) > h(v_1)$$
由此推出 $h(v_1) > h(v_1)$，产生不可调和的逻辑矛盾。因此，**该有向图必定不存在任何环路，即为一个标准的有向无环图（Directed Acyclic Graph, DAG）**。

在 DAG 上，寻找单向递减的最长路径是一个具备严格最优子结构的问题：**从点 $(x, y)$ 出发的最长滑坡长度，完全取决于其所有能够滑向的更低相邻点出发的最长滑坡长度**。

#### 2. 状态定义与记忆化搜索（Memoized DFS）

如果采用不带记忆化的纯暴搜 DFS，从每个格子出发向四个方向递归，最坏情况下同一格会被数以万计的不同搜索路径重复访问，时间复杂度将退化为天文数字级别的指数级 $\mathcal{O}(4^{RC})$，在 $R, C \le 100$ 时会瞬间导致运行超时（TLE）。

为此，我们引入**记忆化搜索**——用空间换时间的动态规划实现方式：
- **状态定义**：设二维数组 $f[x][y]$ 表示**从网格点 $(x, y)$ 开始滑行所能达到的最长滑坡长度（包含自身，因此单点最小长度为 $1$）**。
- **状态转移方程**：
  $$f[x][y] = 1 + \max_{(nx, ny) \in \text{valid\_neighbors}} \{ f[nx][ny] \}$$
  其中 $\text{valid\_neighbors}$ 为满足 $1 \le nx \le R$、$1 \le ny \le C$ 且 $h[nx][ny] < h[x][y]$ 的上下左右相邻点。若没有合法的更低相邻点，则 $f[x][y] = 1$。
- **记忆化剪枝机制**：
  1. 全局数组 $f$ 初始全部赋值为 $0$，表示“该状态尚未被探索与计算”；
  2. 当递归调用 `dfs(x, y)` 时，首先检查 `if (f[x][y] > 0) return f[x][y];`，若已计算过则 $\mathcal{O}(1)$ 立即返回；
  3. 若未计算，先置初始值 $f[x][y] = 1$，然后遍历上下左右 $4$ 个方向，递归求解更低相邻点的最长滑坡并更新当前最大值；
  4. 搜索完成后将最终值写入 $f[x][y]$ 并返回。

由于每个格子 $(x, y)$ 终其一生**仅会真正执行一次深度探索**，其余所有对该点的访问均为 $\mathcal{O}(1)$ 查表返回，重叠子问题被彻底消解。

#### 3. 全局最优解的获取与遍历驱动

注意：题目并未指定滑雪的起点与终点，Michael 可以从整个区域中的**任意一点**作为滑雪起点出发。

因此，主函数只需要遍历网格中的每一个格子 $(i, j)$，分别以它们作为起点调用 `dfs(i, j)`，并在所有返回的长度中取全局最大值：
$$\text{Ans} = \max_{1 \le i \le R, 1 \le j \le C} \{ f[i][j] \}$$

得益于记忆化机制，后续遍历到的起点如果走入了之前已经计算过的区域，会直接利用已存结果，整体常数极小、运行极其平稳。

#### 4. 易错点与边界防坑指南

1. **严格递减与平地判断**：
   - 题面明确说明“当且仅当高度会减小”，即转移条件必须是严格的小于号 `h[nx][ny] < h[x][y]`。
   - 若相邻格子高度相等（平地），不能滑向该点，切勿误写为 `<=`，否则不仅不符合题意，还可能导致死循环。
2. **单点路径长度底线**：
   - 哪怕一个点周围的四个格子高度都比它高（局部最低谷），该点自身的滑坡长度也为 $1$。因此初始化必须保证 $f[x][y] \ge 1$。
3. **坐标界限与方向数组规范**：
   - 行数范围为 $1 \le x \le R$，列数范围为 $1 \le y \le C$。
   - 判定合法性时切勿混淆 $R$ 与 $C$：必须满足 `nx >= 1 && nx <= R && ny >= 1 && ny <= C`。
   - 采用标准方向数组 `dx[4] = {-1, 1, 0, 0}` 与 `dy[4] = {0, 0, -1, 1}` 遍历四联通邻居，逻辑整洁且绝无遗漏。
4. **递归栈深度安全**：
   - 最长路径理论极限可达 $R \times C = 100 \times 100 = 10000$ 层。在 C++ 默认栈空间（通常为 $8\text{MB}$ 或更大）中，单层栈帧仅保存少量整型局部变量（约几十字节），$10000$ 层深度占用内存约几十至数百 KB，绝不会发生系统调用栈溢出（Stack Overflow）。

#### 5. 复杂度深入分析

- **时间复杂度**：
  - 网格总顶点数为 $|V| = R \times C$；
  - 记忆化机制确保了每个顶点 $(x, y)$ 的状态 $f[x][y]$ 只会被完整计算一次；
  - 在计算某个顶点时，只遍历上下左右 $4$ 个邻接方向，状态转移开销为 $\mathcal{O}(1)$；
  - 因此整体算法的时间复杂度严格为：
    $$\mathcal{O}(R \times C)$$
  - 在本题极限规模 $R = 100, C = 100$ 下，$R \times C = 10000$。总计算步骤在 $4 \times 10^4$ 次左右，现代 CPU 耗时小于 $5\text{ms}$，近乎瞬间秒过。
- **空间复杂度**：
  - 高度存储矩阵 `h[105][105]` 与记忆化矩阵 `f[105][105]` 各占用约 $105 \times 105 \times 4 \text{ 字节} \approx 44\text{KB}$；
  - 递归调用栈最深为 $\mathcal{O}(RC)$，占用栈内存不足 $1\text{MB}$；
  - 总体空间复杂度严格为 $\mathcal{O}(R \times C)$，远低于题目的 $125.00\text{MB}$ 内存限制。

### 完整参考代码 (C++11)

```cpp
/**
 * Problem: luogu-P1434 [SHOI2002] 滑雪
 * Algorithm: 记忆化搜索 (Memoized Search) / 网格有向无环图 (DAG) 动态规划
 * Standard: C++11 (CCF GESP 官方大纲规范)
 * Author: OneCoder
 */

#include <iostream>
#include <algorithm>

using namespace std;

// 网格最大规模为 100 x 100，预留边界安全裕量
const int MAXN = 105;

// 网格规模：R 行 C 列
int R, C;

// 存储每个网格点的高度数值
int h[MAXN][MAXN];

// 记忆化数组：f[x][y] 表示从坐标 (x, y) 出发能够滑行的最长滑坡长度
// 全局初始化为 0，表示该格点的最长长度尚未被计算
int f[MAXN][MAXN];

// 四联通方向增量数组：上、下、左、右
const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = {0, 0, -1, 1};

/**
 * 记忆化搜索核心函数 dfs(x, y)
 * 计算并返回以坐标 (x, y) 为起点的最长滑行长度
 */
int dfs(int x, int y) {
    // 1. 记忆化剪枝：如果当前坐标已经计算过最优解，O(1) 直接返回缓存值
    if (f[x][y] > 0) {
        return f[x][y];
    }

    // 2. 基础状态：任何一个点即使无法向外滑行，其自身的滑坡长度也至少为 1
    f[x][y] = 1;

    // 3. 遍历上、下、左、右四个相邻方向
    for (int i = 0; i < 4; ++i) {
        int nx = x + dx[i];
        int ny = y + dy[i];

        // 边界安全检查：保证相邻坐标位于网格内部 [1, R] 与 [1, C]
        if (nx >= 1 && nx <= R && ny >= 1 && ny <= C) {
            // 物理滑行规则：只能从高处向低处滑行（高度严格单调递减）
            if (h[nx][ny] < h[x][y]) {
                // 状态转移：当前最长路径 = max(当前长度, 1 + 从较低相邻点出发的最长路径)
                f[x][y] = max(f[x][y], 1 + dfs(nx, ny));
            }
        }
    }

    // 4. 返回计算好的最长路径长度
    return f[x][y];
}

int main() {
    // 读取区域行数 R 与列数 C
    cin >> R >> C;

    // 读入二维高度矩阵
    for (int i = 1; i <= R; ++i) {
        for (int j = 1; j <= C; ++j) {
            cin >> h[i][j];
            f[i][j] = 0; // 初始化记忆化数组为 0
        }
    }

    int ans = 0;

    // 遍历整个网格中的每一个格子，分别以其作为起点求解最长滑坡，取全局最大值
    for (int i = 1; i <= R; ++i) {
        for (int j = 1; j <= C; ++j) {
            ans = max(ans, dfs(i, j));
        }
    }

    // 输出整个区域中最长滑坡的长度
    cout << ans << "\n";

    return 0;
}
```
