日常生活中打包行李或装载货箱，我们总希望能把有限的箱子空间填得越满越好。洛谷 P1049 [NOIP2001 普及组]《装箱问题》看似在问“剩余空间最小化”，但本质上却是一个将**物品体积等价转化为物品价值**的经典 01 背包变种模型。既然目标是让剩余空间 $V - \sum w$ 最小，等价于在容量 $V$ 的限制下，让装入物品的总体积最大化。理解这种“价值即体积（$v_i = w_i$）”的问题降维映射，并熟练运用滚动数组逆序推导，是深入掌握背包模型拓展应用不可或缺的一课。

## luogu-P1049 [NOIP2001 普及组] 装箱问题

> 🔗 **洛谷原题传送门**：[luogu-P1049 [NOIP2001 普及组] 装箱问题](https://www.luogu.com.cn/problem/P1049)

### 题目描述

有一个箱子容量为 $V$，同时有 $n$ 个物品，每个物品有一个体积。


现在从 $n$ 个物品中，任取若干个装入箱内（也可以不取），使箱子的剩余空间最小。输出这个最小值。

### 输入格式

第一行共一个整数 $V$，表示箱子容量。

第二行共一个整数 $n$，表示物品总数。

接下来 $n$ 行，每行有一个正整数，表示第 $i$ 个物品的体积。

### 输出格式

- 共一行一个整数，表示箱子最小剩余空间。

### 输入输出样例

#### 样例输入 #1

```text
24
6
8
3
12
7
9
7
```

#### 样例输出 #1

```text
0
```

### 说明/提示

对于 $100\%$ 数据，满足 $0<n \le 30$，$1 \le V \le 20000$。

### 题目深度剖析

#### 1. 问题模型的数学抽象与等价转化

初学者在阅读本题时，容易被“使剩余空间最小”所迷惑，试图直接去求剩余空间。实际上，我们可以通过简单的数学关系建立等价映射：
- 设箱子的初始总容量为 $V$；
- 设最终选择装入箱内的物品体积总和为 $S$；
- 则箱子的剩余空间为 $R = V - S$。

因为初始容量 $V$ 是一个固定的常数，要使得 $R = V - S$ 取得最小值，当且仅当装入物品的总体积 $S$ 取得最大值，且 $S \le V$。

因此，原问题“**在容量为 $V$ 的箱子中使剩余空间最小**”，完全等价于：
> **给定背包容量 $V$，有 $n$ 个物品，每个物品的体积为 $v_i$、价值同样为 $v_i$。在不超过总容量 $V$ 的约束下，求能装入物品的最大总价值 $S_{max}$。最终答案即为 $V - S_{max}$。**

通过这一层等价转化，问题直接归约为最纯粹、最基础的 **0/1 背包问题**。

#### 2. 01背包动态规划模型构建

##### （1）状态定义
设二维数组 $dp[i][j]$ 表示：
> **只考虑前 $i$ 个物品，在背包容量上限不超过 $j$ 的情况下，所能装入的最大总体积。**
其中 $0 \le i \le n$，$0 \le j \le V$。

##### （2）状态转移方程
对于第 $i$ 个物品，其体积为 $v_i$，我们只有两种选择：
1. **不选择第 $i$ 个物品**：背包容量不变，此时最大体积继承自前 $i-1$ 个物品在容量 $j$ 下的最优解，即：
   $$dp[i][j] = dp[i - 1][j]$$
2. **选择第 $i$ 个物品**（前提是当前容量 $j \ge v_i$）：背包需预留出 $v_i$ 的空间，由前 $i-1$ 个物品在容量 $j - v_i$ 下的最优解转移而来，并加上当前物品的体积 $v_i$，即：
   $$dp[i][j] = dp[i - 1][j - v_i] + v_i$$

综合两种决策，取最大值：
$$dp[i][j] = \max\big(dp[i - 1][j], \; dp[i - 1][j - v_i] + v_i\big) \quad (j \ge v_i)$$

##### （3）初始条件与目标
- 初始条件：当没有物品可选（$i=0$）或背包容量为 $0$（$j=0$）时，能够装入的最大体积均为 $0$，即 $dp[0][j] = 0$。
- 最终目标：$dp[n][V]$ 即为前 $n$ 个物品放入容量为 $V$ 的背包中所能达到的最大体积。最终输出的剩余空间为 $V - dp[n][V]$。

#### 3. 空间优化：一维滚动数组与逆序遍历的底层本质

在二维转移方程中，我们发现计算 $dp[i][j]$ 时，**仅仅依赖上一阶段 $i-1$ 的状态值**（即 $dp[i-1][j]$ 和 $dp[i-1][j - v_i]$），完全不需要更早之前的历史状态。

因此，我们可以省去第一维空间，将二维数组压缩为一维数组 $dp[j]$：
- **一维状态定义**：$dp[j]$ 表示容量为 $j$ 的背包所能容纳的最大体积。
- **一维状态转移方程**：
  $$dp[j] = \max(dp[j], \; dp[j - v_i] + v_i)$$

##### 为什么 01 背包必须逆序遍历？
在一维滚动数组中，内层循环对容量 $j$ 的遍历顺序至关重要：
- **若正序遍历（$j$ 从 $v_i$ 到 $V$）**：
  当计算到容量 $j$ 时，较小容量的 $dp[j - v_i]$ 在当前这轮循环中已经被更新过了（即已经包含了第 $i$ 个物品），再次使用它就会导致第 $i$ 个物品被**重复使用多次**——这恰恰是完全背包的行为（如我们在 P1616 中所见）。
- **必须逆序遍历（$j$ 从 $V$ 倒序递减至 $v_i$）**：
  倒序遍历能够确保在更新 $dp[j]$ 时，所访问的 $dp[j - v_i]$ 仍然保存的是**上一轮（尚未考虑第 $i$ 个物品时）的旧状态**。这就从数学上严格保证了每个物品至多只会被选择一次，完美契合 0/1 背包的本质约束！

#### 4. 复杂度分析与时空开销

- **时间复杂度**：
  外层循环遍历 $n$ 个物品，内层循环遍历容量 $j$（步数为 $V - v_i + 1 \le V$）。因此总时间复杂度为 $\mathcal{O}(n \times V)$。
  本题数据范围 $n \le 30$，$V \le 20000$，最大运算次数为 $30 \times 20000 = 6 \times 10^5$ 次。在计算机每秒约 $10^8$ 次的运算能力下，执行时间小于 $0.005$ 秒，远低于题目给定的 1.0 秒时限。
- **空间复杂度**：
  使用一维滚动数组后，仅需开辟一个大小为 $V + 5$ 的整型数组 `dp[MAXV]`。对于 $V \le 20000$，数组仅占用内存约 $20000 \times 4 \text{ B} \approx 80 \text{ KB}$，远远低于 $128 \text{ MB}$ 的空间上限。

#### 5. 易错点与边界防坑指南

1. **容量边界与下界控制**：
   内层循环终止条件必须为 `j >= v[i]`，当容量小于当前物品体积时，物品根本放不进背包，无需也不应进行状态更新。
2. **全局数组声明与初始置零**：
   将 `dp` 数组声明在全局变量区（BSS 段），全局数组会自动清零，且能避免将大数组分配在栈内存（Linux 栈空间通常限制为 8MB）中引发潜在的运行时段错误（RE）。
3. **最终结果别忘相减**：
   许多考生在赛场上写完 0/1 背包模板后，习惯性地直接输出了 `dp[V]`，而本题要求的是**最小剩余空间**，切记最终输出的是 `V - dp[V]`！

### C++ 源码实现

```cpp
/**
 * 题目: 【GESP/CSP练习】GESP六级 / CSP-J 题解：luogu-P1049 [NOIP2001 普及组] 装箱问题
 * 题号: P1049
 * 归属: GESP六级 / CSP-J
 * 博客: https://www.coderli.com/gesp-6-luogu-p1049-packing-problem/
 * 标准: C++11 (CCF GESP / CSP 官方规范)
 */

#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

// 箱子最大容量 V <= 20000，定义在全局静态存储区预留安全裕量
const int MAXV = 20005;

// 一维滚动数组：dp[j] 表示在当前容量限制为 j 的条件下，能够装入物品的最大总体积
int dp[MAXV];

int main() {
    int V, n;
    // 读入箱子总容量 V
    cin >> V;
    // 读入物品总数 n
    cin >> n;

    // 读入每个物品的体积
    vector<int> v(n);
    for (int i = 0; i < n; ++i) {
        cin >> v[i];
    }

    // 0/1 背包核心动态规划过程
    // 外层循环：逐一考察每一个物品
    for (int i = 0; i < n; ++i) {
        // 内层循环：逆序遍历背包容量 j（从最大容量 V 倒序递减至当前物品体积 v[i]）
        // 逆序遍历是 0/1 背包的关键：确保每个物品至多被使用一次
        for (int j = V; j >= v[i]; --j) {
            // 状态转移方程：比较不装该物品（dp[j]）与装入该物品（dp[j - v[i]] + v[i]）的体积
            dp[j] = max(dp[j], dp[j - v[i]] + v[i]);
        }
    }

    // dp[V] 即为在容量为 V 时所能装入物品的最大总体积
    // 题目要求最小剩余空间，因此最终结果为总容量 V 减去装入的最大体积 dp[V]
    cout << V - dp[V] << "\n";

    return 0;
}
```
