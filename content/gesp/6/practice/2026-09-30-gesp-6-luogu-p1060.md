面对手头的固定预算和心仪物品的清单，每一件物品既有本身的价格，又有主观的喜爱重要度，如何在预算硬约束下让“开心程度”达到顶峰？洛谷 P1060 [NOIP2006 普及组]《开心的金明》生动刻画了现实消费中的多属性权衡决策。题目的数学本质依然是 01 背包，但其精妙之处在于将物品的收益定义为“价格 $\times$ 重要度”的权值乘积。通过清晰辨识决策状态（买或不买）、容量约束与加权收益，考生能透彻领悟动态规划面对多元衍生指标时的状态转移本质。

## luogu-P1060 [NOIP2006 普及组] 开心的金明

> 🔗 **洛谷原题传送门**：[luogu-P1060 [NOIP2006 普及组] 开心的金明](https://www.luogu.com.cn/problem/P1060)

### 题目描述

金明今天很开心，家里购置的新房就要领钥匙了，新房里有一间他自己专用的很宽敞的房间。更让他高兴的是，妈妈昨天对他说：“你的房间需要购买哪些物品，怎么布置，你说了算，只要不超过$N$元钱就行”。今天一早金明就开始做预算，但是他想买的东西太多了，肯定会超过妈妈限定的$N$元。于是，他把每件物品规定了一个重要度，分为$5$等：用整数$1-5$表示，第$5$等最重要。他还从因特网上查到了每件物品的价格（都是整数元）。他希望在不超过$N$元（可以等于$N$元）的前提下，使每件物品的价格与重要度的乘积的总和最大。

设第$j$件物品的价格为$v[j]$，重要度为$w[j]$，共选中了$k$件物品，编号依次为$j_1,j_2,…,j_k$，则所求的总和为：

$v[j_1] \times w[j_1]+v[j_2] \times w[j_2]+ …+v[j_k] \times w[j_k]$。

请你帮助金明设计一个满足要求的购物单。


### 输入格式

第一行，为$2$个正整数，用一个空格隔开：$n,m$（其中$N(<30000)$表示总钱数，$m(<25)$为希望购买物品的个数。）

从第$2$行到第$m+1$行，第$j$行给出了编号为$j-1$的物品的基本数据，每行有$2$个非负整数$ v p$（其中$v$表示该物品的价格$(v \le 10000)$，$p$表示该物品的重要度($1-5$)

### 输出格式

$1$个正整数，为不超过总钱数的物品的价格与重要度乘积的总和的最大值$(<100000000)$。


### 输入输出样例

#### 样例输入 #1
```
1000 5
800 2
400 5
300 5
400 3
200 2
```

#### 样例输出 #1

```
3900
```

### 题目深度剖析

#### 1. 问题模型的数学抽象与等价映射

本题是一道非常纯粹且标准的 **0/1 背包问题（0/1 Knapsack Problem）**。为了理清算法思路，我们首先将实际题目背景与经典 0/1 背包模型进行严格的变量对应与映射：

- **背包容量**：金明拥有的总预算为 $N$ 元，因此背包的最大承重/容量上限即为 $N$。
- **物品数量**：共有 $m$ 件候选物品。
- **物品成本（体积）**：每件物品的价格为 $v_i$，购买该物品需要花费 $v_i$ 元，即占用 $v_i$ 的背包容量。
- **物品收益（价值）**：题目明确规定所求目标为“价格与重要度乘积的总和最大”，因此第 $i$ 件物品的价值并不是其单纯的重要度 $p_i$，而是：
  $$w_i = v_i \times p_i$$
- **决策约束**：每件物品只有“买”与“不买”两种状态，且每件物品至多只能购买一次，满足经典的 0/1 特性。

基于上述映射，问题转化为：
> **在总成本不超过 $N$ 的前提下，从 $m$ 件物品中选择若干件，使得选出的物品价值 $w_i = v_i \times p_i$ 之和达到最大值。**

#### 2. 01背包动态规划模型构建

##### （1）状态定义
设二维数组 $dp[i][j]$ 表示：
> **只考虑前 $i$ 件物品，在花费预算上限不超过 $j$ 元的情况下，所能获取的最大“价格 $\times$ 重要度”乘积之和。**
其中 $0 \le i \le m$，$0 \le j \le N$。

##### （2）状态转移方程
对于第 $i$ 件物品（价格为 $v_i$，重要度为 $p_i$，价值 $w_i = v_i \times p_i$），存在两种互斥决策：
1. **不购买第 $i$ 件物品**：当前可用预算不变，最优收益直接继承自前 $i-1$ 件物品在预算 $j$ 下的最优解：
   $$dp[i][j] = dp[i - 1][j]$$
2. **购买第 $i$ 件物品**（前提是当前预算 $j \ge v_i$）：需要扣除该物品的购买成本 $v_i$，状态由前 $i-1$ 件物品在剩余预算 $j - v_i$ 下的最优解转移而来，并加上当前物品的收益 $w_i$：
   $$dp[i][j] = dp[i - 1][j - v_i] + v_i \times p_i$$

综合上述决策，为了使总价值最大，状态转移方程为：
$$dp[i][j] = \max\big(dp[i - 1][j], \; dp[i - 1][j - v_i] + v_i \times p_i\big) \quad (j \ge v_i)$$

##### （3）初始条件与边界
- 当没有物品可选（$i=0$）或预算为 $0$（$j=0$）时，能获取的最大收益显然为 $0$，即 $dp[0][j] = 0$。
- 最终目标值即为 $dp[m][N]$。

#### 3. 空间优化：一维滚动数组与逆序遍历的底层机理

在二维状态转移方程中，计算阶段 $i$ 的状态值仅依赖于阶段 $i-1$（即前一阶段）的状态，与更早之前的历史阶段无关。因此，我们可以省去第一维空间，将空间复杂度从 $\mathcal{O}(m \times N)$ 优化到 $\mathcal{O}(N)$。

设一维数组 $dp[j]$ 表示预算上限为 $j$ 元时所能获得的最大收益，状态转移方程简化为：
$$dp[j] = \max(dp[j], \; dp[j - v_i] + v_i \times p_i)$$

##### 为什么 0/1 背包必须逆序遍历？
在一维滚动数组中，内层循环遍历预算 $j$ 的顺序至关重要：
- **若正序遍历（$j$ 从 $v_i$ 递增至 $N$）**：
  在计算较大的预算容量 $j$ 时，较小的容量 $j - v_i$ 在本轮循环中已经被更新过了（即已经包含了第 $i$ 件物品）。此时再次使用 $dp[j - v_i]$ 来更新 $dp[j]$，就会导致第 $i$ 件物品被**重复累加购买多次**，变成了完全背包（如洛谷 P1616）。
- **必须逆序遍历（$j$ 从 $N$ 倒序递减至 $v_i$）**：
  倒序递减能严格保证在更新 $dp[j]$ 时，所访问的 $dp[j - v_i]$ 依然保存的是**上一轮循环（尚未选购第 $i$ 件物品）**的历史状态值。这就从数学上严格锁定了每件物品至多只能被选购一次的排他性约束，保证了 0/1 背包逻辑的正确性。

#### 4. 复杂度分析与时空开销

- **时间复杂度**：
  外层循环遍历 $m$ 件物品，内层循环逆序遍历预算 $j$（步数不超过 $N - v_i + 1 \le N$）。因此算法总时间复杂度为 $\mathcal{O}(m \times N)$。
  根据题目给出的数据范围：$N < 30000$，$m < 25$。
  最大基本操作次数仅为 $25 \times 30000 = 7.5 \times 10^5$ 次。在现代评测机每秒约 $10^8$ 次的运算基准下，程序耗时小于 $0.005$ 秒，远低于题目设定的 1.0 秒时限。
- **空间复杂度**：
  采用一维滚动数组后，仅需维护一个大小为 $N + 5$ 的整型数组 `dp[MAXN]`。对于 $N < 30000$，数组仅占用内存约 $30000 \times 4 \text{ B} \approx 120 \text{ KB}$，远远低于题目规定的 $128 \text{ MB}$ 内存上限。

#### 5. 易错点与边界防坑指南

1. **价值计算定义**：
   切忌直接将输入的重要度 $p$ 作为物品价值进行背包转移！题目明确指出最大化的是“价格与重要度乘积的总和”，因此每次转移累加的收益必须是 $v \times p$。
2. **数据范围与整型溢出判断**：
   题目输出格式提示最大可能结果 $< 10^8$。C++ 中 32 位带符号整型 `int` 的表示范围约为 $-2.14 \times 10^9 \sim 2.14 \times 10^9$，因此使用普通 `int` 完全安全，不会出现整型溢出。
3. **内层循环下界控制**：
   内层逆序遍历的下界必须终止在 `j >= v`，当当前可用预算小于物品价格 $v$ 时，金明无法购买该物品，不可继续扣减，避免产生数组负下标越界访问。
4. **在线流式读入**：
   由于每件物品只在内层循环中处理一次，处理完后无需在后续阶段重复查询其原始价格与重要度，因此完全可以在读入时直接进行 DP 转移，连物品数组都无需额外开辟，代码极度优雅精简。

### C++ 源码实现

```cpp
/**
 * 题目: 【GESP/CSP练习】GESP六级 / CSP-J 题解：luogu-P1060 [NOIP2006 普及组] 开心的金明
 * 题号: P1060
 * 归属: GESP六级 / CSP-J
 * 博客: https://www.coderli.com/gesp-6-luogu-p1060/
 * 标准: C++11 (CCF GESP / CSP 官方规范)
 */

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 总预算 N < 30000，定义在全局静态存储区，预留安全边界
const int MAXN = 30005;

// 一维滚动数组：dp[j] 表示在预算上限为 j 元时，能获得的最大“价格与重要度乘积”总和
int dp[MAXN];

int main() {
    int n, m;
    // 读入总钱数 n 与希望购买的物品总数 m
    cin >> n >> m;

    // 0/1 背包动态规划过程
    // 逐一读入并处理每个物品，无需预先保存全部物品数组，节省内存空间
    for (int i = 0; i < m; ++i) {
        int v, p;
        cin >> v >> p;
        int value = v * p; // 当前物品的实际收益（价值）：价格 * 重要度

        // 逆序枚举当前预算 j（从总钱数 n 倒序递减至当前物品价格 v）
        // 核心机制：逆序遍历确保在更新 dp[j] 时，所引用的 dp[j - v] 来自上一轮未放入当前物品的状态，
        // 从而严格保证每件物品至多被选购一次（0/1 背包特性）
        for (int j = n; j >= v; --j) {
            dp[j] = max(dp[j], dp[j - v] + value);
        }
    }

    // dp[n] 即为在不超过 n 元预算的前提下，所能获得的最大乘积总和
    cout << dp[n] << "\n";

    return 0;
}
```
