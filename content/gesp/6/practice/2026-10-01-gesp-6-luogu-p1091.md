排练合唱队形时，如何让队列呈现先严格递增、后严格递减的“山峰形（单峰形）”，同时移走尽可能少的同学？洛谷 P1091 [NOIP2004 提高组]《合唱队形》是线性动态规划中**双向最长上升子序列（Double LIS）**的传世经典。题目要求“移走人数最少”，反向思考即为“保留人数最多”。通过分别从左向右求出以每个同学为结尾的 LIS，再从右向左求出从每个同学开始的 LDS（反向 LIS），二者在顶峰拼接求最大值，将原本复杂的双向约束解耦为两个独立子问题。这道题目是 GESP 六级与 CSP 提高组训练子序列模型与状态合并的必修经典。

## luogu-P1091 [NOIP2004 提高组] 合唱队形

> 🔗 **洛谷原题传送门**：[luogu-P1091 [NOIP2004 提高组] 合唱队形](https://www.luogu.com.cn/problem/P1091)

### 题目描述

$n$ 位同学站成一排，音乐老师要请其中的 $n-k$ 位同学出列，使得剩下的 $k$ 位同学排成合唱队形。

合唱队形是指这样的一种队形：设 $k$ 位同学从左到右依次编号为 $1,2,$ … $,k$，他们的身高分别为 $t_1,t_2,$ … $,t_k$，则他们的身高满足 $t_1< \cdots <t_i>t_{i+1}>$ … $>t_k(1\le i\le k)$。

你的任务是，已知所有 $n$ 位同学的身高，计算最少需要几位同学出列，可以使得剩下的同学排成合唱队形。

### 输入格式

共二行。

第一行是一个整数 $n$（$2\le n\le100$），表示同学的总数。

第二行有 $n$ 个整数，用空格分隔，第 $i$ 个整数 $t_i$（$130\\le t_i\\le230$）是第 $i$ 位同学的身高（厘米）。

### 输出格式

一个整数，最少需要几位同学出列。


### 输入输出样例

#### 样例输入 #1
```text
8
186 186 150 200 160 130 197 220
```

#### 样例输出 #1

```text
4
```

### 说明/提示

对于 $50\%$ 的数据，保证有 $n \le 20$。

对于全部的数据，保证有 $n \le 100$。

---

### 题目深度剖析

#### 1. 问题模型的数学抽象与等价转化

本题所定义的合唱队形数学表达式为：
$$t_1 < t_2 < \dots < t_i > t_{i+1} > \dots > t_k \quad (1 \le i \le k)$$

观察该结构可以提炼出三个关键特性：
1. **严格单调性**：队形由一段严格递增序列和一段严格递减序列拼接而成，序列中相邻身高严禁相等（严格小于或严格大于）。
2. **退化边界成立**：当 $i = 1$ 时，整个队形退化为纯单调严格下降序列；当 $i = k$ 时，整个队形退化为纯单调严格上升序列。这两种极端情况完全符合题目定义中的边界约束。
3. **互补转化思维**：总人数 $n$ 是固定的常量，音乐老师需要让 $n - k$ 位同学出列。要让出列人数 $n - k$ **最小化**，根据恒等式：
   $$\min(n - k) = n - \max(k)$$
   问题完全等价于：**在原序列中寻找一个长度最大的子序列，使其满足单峰严格增减的合唱队形要求**。

#### 2. 状态设计与双向动态规划（Bilateral DP）

若直接在序列中全局搜索单峰，由于峰顶位置未知，左右分支互相牵扯。解决此类问题的经典策略是**枚举核心枢纽（以峰顶为基准点拆分）**：

假设队伍的最高峰（转折点）恰好是原序列中的第 $i$ 位同学（$1 \le i \le n$），那么：
- 在第 $i$ 位同学的左侧（下标 $1 \dots i$），必须选出一个以第 $i$ 位同学为结尾的**严格单调递增子序列**。
- 在第 $i$ 位同学的右侧（下标 $i \dots n$），必须选出一个以第 $i$ 位同学为开头的**严格单调递减子序列**。

为了最大化以 $i$ 为峰顶的队形总人数，左侧上升序列和右侧下降序列必须分别达到各自可能的最长长度。因此，我们设计两个一维动态规划状态：

##### （1）正向 LIS：计算以每位同学为结尾的最长上升子序列
- **状态定义**：设 $dp_{\text{left}}[i]$ 表示在子区间 $[1, i]$ 中，**以第 $i$ 位同学为结尾**的严格单调递增子序列的最大长度。
- **初始状态**：第 $i$ 位同学自身总能构成一个长度为 $1$ 的上升子序列，即：
  $$dp_{\text{left}}[i] = 1 \quad (1 \le i \le n)$$
- **状态转移方程**：枚举第 $i$ 位同学前面的所有前驱同学 $j$（$1 \le j < i$），若 $t_j < t_i$，则第 $i$ 位同学可以接在以 $j$ 结尾的上升子序列之后：
  $$dp_{\text{left}}[i] = \max_{1 \le j < i, \, t_j < t_i} \{ dp_{\text{left}}[j] + 1 \}$$

##### （2）反向 LIS / LDS：计算以每位同学为起点的最长下降子序列
- **状态定义**：设 $dp_{\text{right}}[i]$ 表示在子区间 $[i, n]$ 中，**以第 $i$ 位同学为起点**的严格单调递减子序列的最大长度（等价于从右往左看、以 $i$ 结尾的最长上升子序列）。
- **初始状态**：第 $i$ 位同学自身构成长度为 $1$ 的下降子序列：
  $$dp_{\text{right}}[i] = 1 \quad (1 \le i \le n)$$
- **状态转移方程**：从右向左逆向枚举，考察第 $i$ 位同学后面的所有后继同学 $j$（$i < j \le n$），若 $t_j < t_i$，说明第 $j$ 位同学可以作为递减序列的下一棒：
  $$dp_{\text{right}}[i] = \max_{i < j \le n, \, t_j < t_i} \{ dp_{\text{right}}[j] + 1 \}$$

#### 3. 全局极值汇总与去重合并

当预处理得到所有的 $dp_{\text{left}}[i]$ 与 $dp_{\text{right}}[i]$ 后，我们枚举每一个可能的峰顶位置 $i$（$1 \le i \le n$）：
- 此时构成的合唱队形中，左侧递增段有 $dp_{\text{left}}[i]$ 人（包含同学 $i$）；
- 右侧递减段有 $dp_{\text{right}}[i]$ 人（同样包含同学 $i$）；
- 显然，第 $i$ 位同学在两个子序列中各被统计了一次。因此以同学 $i$ 为峰顶最多能保留的人数为：
  $$K(i) = dp_{\text{left}}[i] + dp_{\text{right}}[i] - 1$$

最终最大保留人数为：
$$\max(k) = \max_{1 \le i \le n} \{ dp_{\text{left}}[i] + dp_{\text{right}}[i] - 1 \}$$
最少出列人数即为 $n - \max(k)$。

### 样例手推演算

以样例数据为例：
- $n = 8$
- 身高数组 $t = [186, 186, 150, 200, 160, 130, 197, 220]$

我们逐步执行双向 DP 状态推导：

| 下标 $i$ | 身高 $t[i]$ | $dp_{\text{left}}[i]$ (正向 LIS) | 转移来源解析 | $dp_{\text{right}}[i]$ (反向 LDS) | 转移来源解析 | $K(i) = \text{左} + \text{右} - 1$ |
| :---: | :---: | :---: | :--- | :---: | :--- | :---: |
| 1 | 186 | 1 | 自身基础值 | 3 | $186 > 160 > 130$ | $1 + 3 - 1 = 3$ |
| 2 | 186 | 1 | 与前一位相等不能严格上升 | 3 | $186 > 160 > 130$ | $1 + 3 - 1 = 3$ |
| 3 | 150 | 1 | 无更小的前驱 | 2 | $150 > 130$ | $1 + 2 - 1 = 2$ |
| 4 | 200 | 2 | $186 < 200$ 或 $150 < 200$ | 3 | $200 > 160 > 130$ | $2 + 3 - 1 = 4$ |
| 5 | 160 | 2 | $150 < 160$ | 2 | $160 > 130$ | $2 + 2 - 1 = 3$ |
| 6 | 130 | 1 | 最小值 | 1 | 自身基础值 | $1 + 1 - 1 = 1$ |
| 7 | 197 | 3 | $150 < 160 < 197$ | 1 | 自身基础值 | $3 + 1 - 1 = 3$ |
| 8 | 220 | 4 | $150 < 160 < 197 < 220$ | 1 | 自身基础值 | $4 + 1 - 1 = 4$ |

遍历所有峰顶位置，发现当选择第 4 位同学（身高 200，队形 $150, 200, 160, 130$）或第 8 位同学（身高 220，队形 $150, 160, 197, 220$）为峰顶时，$K(i)$ 均可达到最大值 $4$。

此时最多保留 $k = 4$ 人，最少出列人数为 $n - k = 8 - 4 = 4$ 人，与样例输出完全吻合。

### 易错点与边界防坑指南

1. **严格单调性（严禁使用 `<=` 或 `>=`）**：
   题目要求 $t_1 < \dots < t_i > \dots > t_k$，在转移时必须使用严格的大于/小于号 `t[j] < t[i]`。若写成 `<=` 会将身高相同的同学纳入递增序列，导致不满足合唱队形定义。
2. **中心峰顶重复统计陷阱**：
   在合并左侧长度与右侧长度时，必须执行 `- 1` 操作。因为第 $i$ 位同学既是左侧递增的终点，也是右侧递减的起点，直接相加会导致该同学被重复计算。
3. **平原或单调序列边界情况**：
   - 若原序列完全单调递增（如 $130, 140, 150, 160$），当 $i = n$ 时，$dp_{\text{left}}[n] = n, dp_{\text{right}}[n] = 1$，得出 $K(n) = n + 1 - 1 = n$，需要出列 $0$ 人，完全符合单峰退化情形。
   - 若所有同学身高完全相同（如 $180, 180, 180$），由于要求严格增减，任何峰顶计算出来的 $dp_{\text{left}}$ 与 $dp_{\text{right}}$ 均为 $1$，$K(i) = 1 + 1 - 1 = 1$，最多保留 $1$ 人，出列 $n - 1$ 人，推导完全自洽。
4. **复杂度评估**：
   数据规模保证 $n \le 100$。双向 DP 采用双重循环，时间复杂度为 $2 \times O(n^2) = O(n^2)$，操作次数在 $10^4$ 级别之内，耗时 $< 1\text{ms}$，在 1.00s 限制内绰绰有余。空间复杂度开销仅为几个大小为 $100$ 的一维数组，耗费内存 $< 1\text{MB}$。

### C++11 参考代码

```cpp
/**
 * 题目: 【NOIP真题】2004 合唱队形 luogu-P1091 | 适用于 GESP六级 / CSP-J 练习
 * 题号: P1091
 * 考点: 线性动态规划 / 双向最长上升子序列 (Bilateral LIS)
 * 归属: GESP六级 / CSP-J
 * 标准: C++11 (CCF GESP / CSP 官方规范)
 */

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 最大人数 N <= 100，设置全局安全边界
const int MAXN = 105;

// t 数组存储每位同学的身高（厘米）
int t[MAXN];
// dp_left[i] 表示以第 i 位同学为结尾的最长严格上升子序列（LIS）长度
int dp_left[MAXN];
// dp_right[i] 表示以第 i 位同学为起点的最长严格下降子序列（LDS）长度
int dp_right[MAXN];

int main() {
    int n;
    cin >> n;

    // 读入每位同学的身高，下标从 1 开始
    for (int i = 1; i <= n; ++i) {
        cin >> t[i];
    }

    // 1. 正向动态规划：计算以每位同学为结尾的最长严格上升子序列长度
    for (int i = 1; i <= n; ++i) {
        dp_left[i] = 1; // 基础情况：自身至少构成长度为 1 的子序列
        for (int j = 1; j < i; ++j) {
            // 严格递增条件
            if (t[j] < t[i]) {
                dp_left[i] = max(dp_left[i], dp_left[j] + 1);
            }
        }
    }

    // 2. 反向动态规划：计算以每位同学为起点的最长严格下降子序列长度
    // 逆向遍历等价于求从右往左看的最长上升子序列
    for (int i = n; i >= 1; --i) {
        dp_right[i] = 1; // 基础情况：自身至少构成长度为 1 的子序列
        for (int j = n; j > i; --j) {
            // 严格递减条件（后方同学身高小于当前同学）
            if (t[j] < t[i]) {
                dp_right[i] = max(dp_right[i], dp_right[j] + 1);
            }
        }
    }

    // 3. 枚举最高峰顶（C位）的位置 i，寻找保留人数最多的合唱队形
    int max_retain = 0;
    for (int i = 1; i <= n; ++i) {
        // 第 i 位同学在左侧上升末尾和右侧下降起点各计算了一次，去重减 1
        int current_k = dp_left[i] + dp_right[i] - 1;
        max_retain = max(max_retain, current_k);
    }

    // 4. 最少出列人数 = 总人数 - 最多保留人数
    cout << n - max_retain << endl;

    return 0;
}
```
