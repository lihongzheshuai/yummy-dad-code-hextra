树结构作为非线性数据结构的核心代表，任意两个节点之间的拓扑亲缘关系判定是图论与树算法的基石。洛谷 P3379「【模板】最近公共祖先（LCA）」是 CCF GESP 七级与 CSP-S 组别中最基础且最重要的经典模板题之一。题目要求在一棵具有 $N$ 个节点且以 $S$ 为根的有根多叉树上，高效响应 $M$ 次关于两点最近公共祖先（Lowest Common Ancestor, LCA）的在线查询。面对 $N, M \le 500000$ 的超大数据规模，朴素的一步步向上追溯（暴力爬树）在退化成长链的树形结构上，单次查询时间复杂度高达 $O(N)$，整体时间复杂度 $O(N \cdot M)$ 会彻底超时（TLE）。攻克海量 LCA 查询的核心利器是**树上倍增法（Binary Lifting）**：基于二进制拆分思想，通过预处理 $O(N \log N)$ 规模的祖先跃迁表，将两点深度对齐与祖先逼近过程从线性步长压缩至对数阶，实现 $O(\log N)$ 单次快速查询；结合广度优先遍历（BFS）预处理更能彻底杜绝深链树递归爆栈的工程隐患。题目洛谷官方难度评级为`普及/提高-`。

## luogu-P3379 【模板】最近公共祖先（LCA）

> 🔗 **洛谷原题传送门**：[luogu-P3379 【模板】最近公共祖先（LCA）](https://www.luogu.com.cn/problem/P3379)

### 题目描述

如题，给定一棵有根多叉树，请求出指定两个点直接最近的公共祖先。


## 输入格式

第一行包含三个正整数 $N,M,S$，分别表示树的结点个数、询问的个数和树根结点的序号。

接下来 $N-1$ 行每行包含两个正整数 $x, y$，表示 $x$ 结点和 $y$ 结点之间有一条直接连接的边（数据保证可以构成树）。

接下来 $M$ 行每行包含两个正整数 $a, b$，表示询问 $a$ 结点和 $b$ 结点的最近公共祖先。


## 输出格式

输出包含 $M$ 行，每行包含一个正整数，依次为每一个询问的结果。

### 题目深度剖析

#### 1. 朴素算法为何失效？（长链退化与 TLE 瓶颈）

在探讨倍增算法前，先审视最直观的朴素爬树解法：
- **朴素爬树流程**：
  1. 预处理求出每个节点的深度 $\text{depth}$ 以及直接父节点 $\text{parent}$；
  2. 若两点深度不同，先让深度较深的节点一步一步向上爬，直到两点处于同一深度；
  3. 两点同深度后，若两点未重合，则两点同时一步一步向上爬，直至第一次相遇，相遇节点即为 LCA。
- **长链退化反例**：若树的拓扑结构退化为一条深度为 $N$ 的单链（例如 $1-2-3-\dots-N$），根节点为 $1$。若询问链底节点 $N$ 与节点 $N-1$ 的 LCA，单次查询需要向上爬 $O(N)$ 步。
- **复杂度失控**：题目中 $N, M \le 500000$。在极端退化数据下，总计算步数高达 $500000 \times 500000 = 2.5 \times 10^{11}$ 次。洛谷官方 2021/10/4 特别加入的长链测试点，正是为了坚决卡掉这种暴力跳跃解法。

#### 2. 二进制拆分与树上倍增（Binary Lifting）核心数学原理

计算机底层依托二进制运行。任意正整数 $D$ 均可唯一且无遗漏地分解为若干个 2 的非负整数次幂之和：
$$D = \sum_{i=0}^{\lfloor \log_2 D \rfloor} c_i \cdot 2^i \quad (c_i \in \{0, 1\})$$

由此启发我们：**若将向上爬一步的线性移动，改造为以 $2^k$ 步为基本单位的指数跃迁，则任何距离 $D$ 的攀爬过程都可以在至多 $\lceil \log_2 D \rceil$ 步内精准完成！**

- **状态定义**：
  设 $\text{parent\_node}[u][k]$ 表示节点 $u$ 沿树向上跳跃 $2^k$ 步所到达的祖先节点编号。若跳跃超出根节点，则将其指向虚拟边界节点 $0$。
- **状态转移递推方程**：
  由于 $2^k = 2^{k-1} + 2^{k-1}$，节点 $u$ 向上跳 $2^k$ 步，等价于先从 $u$ 向上跳 $2^{k-1}$ 步到达中转节点 $mid = \text{parent\_node}[u][k-1]$，再从 $mid$ 继续向上跳 $2^{k-1}$ 步。因此递推关系为：
  $$\text{parent\_node}[u][k] = \text{parent\_node}[\text{parent\_node}[u][k-1]][k-1]$$
- **幂次上界确定**：
  题目数据中 $N \le 500000$。因为 $2^{18} = 262144 < 500000$ 且 $2^{19} = 524288 > 500000$，倍增最大幂次选取 $k \le 20$（即常量 $\text{MAXLOG} = 21$）即可绝对覆盖树上任意两点之间的最大可能距离。

#### 3. 倍增 LCA 查询的两阶段推进法

对于任意一次询问 $(u, v)$，最近公共祖先的求解严格分为两阶段推进：

1. **第一阶段：深度对齐（深节点向浅节点二分靠拢）**
   - 设两点深度分别为 $\text{depth}[u]$ 与 $\text{depth}[v]$。不妨设 $\text{depth}[u] \ge \text{depth}[v]$（若不满足则交换 $u$ 与 $v$）。
   - 计算两者的深度差值。从最高幂次 $k = \text{MAXLOG}-1$ 开始向下遍历至 $k = 0$：
     若 $\text{depth}[u] - 2^k \ge \text{depth}[v]$，则令 $u = \text{parent\_node}[u][k]$。
   - 二进制拆分保证在循环结束后，节点 $u$ 必然精确提升至与 $v$ 相同的深度。
   - **边界特判**：若对齐后发现 $u == v$，说明原先较浅的节点 $v$ 本身就是 $u$ 的祖先，此时直接返回 $u$ 即可。

2. **第二阶段：同步倍增逼近（保持异名向上跳跃）**
   - 此时 $u$ 与 $v$ 深度严格相等且 $u \neq v$。
   - 同样从最高幂次 $k = \text{MAXLOG}-1$ 向下递减至 $k = 0$ 尝试同步跃迁：
     - 若 $\text{parent\_node}[u][k] \neq \text{parent\_node}[v][k]$：说明向上跳 $2^k$ 步后，两点尚未到达公共祖先（或者尚未相聚），这次跳跃是安全的，执行同步跳跃：$u = \text{parent\_node}[u][k], v = \text{parent\_node}[v][k]$；
     - 若 $\text{parent\_node}[u][k] == \text{parent\_node}[v][k]$：说明向上跳 $2^k$ 步后已经到达了某个公共祖先，但该祖先不一定是**最近**公共祖先（可能跳过了头）。为了不跨越 LCA，此时保持两节点在原地不动，继续尝试更小的幂次步长 $2^{k-1}$。
   - **收敛结果**：当循环递减至 $k = 0$ 结束时，$u$ 与 $v$ 必然恰好停在最近公共祖先的正下方直接子节点位置。
   - **返回答案**：两者的直接父节点 $\text{parent\_node}[u][0]$ 即为所求的最近公共祖先！

#### 4. 工程与竞赛避坑指南：BFS 层序遍历 vs DFS 递归

在树形算法中，许多教材习惯使用深度优先搜索（DFS）递归预处理倍增表。然而在工业级工程与高规格竞赛中，面对 $N = 500000$ 的超大规模数据，DFS 存在致命缺陷：
- **DFS 爆栈隐患**：若输入数据退化为一条长链，DFS 递归调用栈将深入 500000 层。Linux 环境下默认函数栈通常为 8MB，如此深度的函数调用栈会瞬间导致栈溢出（Stack Overflow，报 SIGSEGV / 运行错误）；
- **BFS 稳健方案**：采用广度优先搜索（BFS）层序遍历。队列动态分配于堆空间中，函数调用栈深度严格保持为 $O(1)$。从给定的根节点 $S$ 开始，逐层向下拓展，在计算子节点深度的同时同步建立倍增表，彻底规避爆栈风险。

### C++11 标准参考程序

```cpp
/**
 * 题目: 【GESP/CSP练习】GESP七级 / CSP-S 题解：luogu-P3379 【模板】最近公共祖先（LCA）
 * 题号: P3379
 * 归属: GESP七级 / CSP-S / 树论与树上倍增模板题
 * 博客: https://www.coderli.com/gesp-7-luogu-p3379/
 * 标准: C++11 (严格遵循 CCF GESP 官方规范)
 */

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// 最大节点数量与倍增最大幂次（2^20 > 500000）
const int MAXN = 500005;
const int MAXLOG = 21;

// 邻接表存储树的双向边
vector<int> adj[MAXN];

// depth[i] 记录节点 i 在树中的深度（根节点深度设为 1）
int depth[MAXN];

// parent_node[i][k] 记录节点 i 向上跳 2^k 步所到达的祖先节点编号
int parent_node[MAXN][MAXLOG];

/**
 * 广度优先搜索（BFS）层序遍历预处理深度与倍增祖先表
 * 工程优势：彻底规避极端退化链状树在递归深搜（DFS）下的调用栈溢出（Stack Overflow）风险
 * @param root 树根节点编号
 */
void bfs_init(int root) {
    queue<int> q;
    depth[root] = 1;
    parent_node[root][0] = 0; // 根节点的父节点为 0（虚拟边界）
    q.push(root);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : adj[u]) {
            // 跳过通往直接父节点的反向边
            if (v == parent_node[u][0]) {
                continue;
            }

            depth[v] = depth[u] + 1;
            parent_node[v][0] = u; // v 向上跳 2^0 = 1 步即为直接父节点 u

            // 状态转移递推：跳 2^k 步 = 先跳 2^(k-1) 步，再从该中转点跳 2^(k-1) 步
            for (int k = 1; k < MAXLOG; ++k) {
                parent_node[v][k] = parent_node[parent_node[v][k - 1]][k - 1];
            }

            q.push(v);
        }
    }
}

/**
 * 树上倍增法查询任意两点 u 和 v 的最近公共祖先（LCA）
 * @param u 查询节点编号 1
 * @param v 查询节点编号 2
 * @return 节点 u 与 v 的最近公共祖先节点编号
 */
int query_lca(int u, int v) {
    // 规范化：确保 u 始终为深度更深（或相等）的节点
    if (depth[u] < depth[v]) {
        swap(u, v);
    }

    // 第一阶段：深度对齐
    // 利用二进制拆分，从大步长向小步长尝试跳跃，使 u 向上提升至与 v 处于同一深度
    for (int k = MAXLOG - 1; k >= 0; --k) {
        if (depth[u] - (1 << k) >= depth[v]) {
            u = parent_node[u][k];
        }
    }

    // 特判边界：若深度对齐后 u 与 v 重合，说明 v 本身就是 u 的祖先
    if (u == v) {
        return u;
    }

    // 第二阶段：同步倍增逼近
    // 从大到小尝试让 u 与 v 同时向上跳跃 2^k 步
    // 若跳跃后的目标节点不相等，说明尚未到达公共祖先或尚未越过 LCA，同步向上跳
    for (int k = MAXLOG - 1; k >= 0; --k) {
        if (parent_node[u][k] != parent_node[v][k]) {
            u = parent_node[u][k];
            v = parent_node[v][k];
        }
    }

    // 循环结束后，u 与 v 恰好停在 LCA 的正下方直接子节点
    // 其直接父节点 parent_node[u][0] 即为所求的最近公共祖先
    return parent_node[u][0];
}

int main() {
    int n, m, s;
    cin >> n >> m >> s;

    // 读入 n - 1 条无向树边构建邻接表
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 从根节点 s 开始层序遍历初始化
    bfs_init(s);

    // 处理 m 次 LCA 查询
    for (int i = 0; i < m; ++i) {
        int a, b;
        cin >> a >> b;
        cout << query_lca(a, b) << "\n";
    }

    return 0;
}
```

### 算法复杂度全面分析

1. **时间复杂度分析**：
   - **邻接表建图**：读入 $N-1$ 条双向边，耗时 $O(N)$；
   - **BFS 层序预处理**：共有 $N$ 个节点进入队列一次，每个节点计算 $\text{MAXLOG} \approx 20$ 次倍增跳转，预处理耗时 $O(N \log N)$；
   - **单次 LCA 查询**：深度对齐耗时 $O(\log N)$，同步逼近耗时 $O(\log N)$，单次查询总耗时为严格的 $O(\log N)$；
   - **总查询时间**：响应 $M$ 次查询耗时 $O(M \log N)$；
   - **整体时间复杂度**：$O((N + M) \log N)$。代入 $N, M = 500000$ 与 $\log_2 N \approx 19$，基本操作规模约 $1.9 \times 10^7$ 次，远在 1 秒时限内平稳运行。

2. **空间复杂度分析**：
   - **图的邻接表存储**：无向树包含 $2(N - 1)$ 条有向边，`adj` 数组空间为 $O(N)$；
   - **倍增数组**：`parent_node[MAXN][MAXLOG]` 大小为 $500005 \times 21 \times 4\text{ 字节} \approx 42\text{ MB}$；
   - **深度数组与辅助队列**：`depth` 数组与 BFS 队列空间为 $O(N) \approx 4\text{ MB}$；
   - **整体空间复杂度**：$O(N \log N)$，整机内存消耗约 $60\text{ MB}$，完全符合洛谷 512MB 的内存限制。
