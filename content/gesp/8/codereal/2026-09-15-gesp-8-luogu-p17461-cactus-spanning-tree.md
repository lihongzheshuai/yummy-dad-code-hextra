## P17461 [GESP202609 八级] 生成树计数

> 🔗 **洛谷原题传送门**：[P17461](https://www.luogu.com.cn/problem/P17461)

### 题目描述

给定一张有 $n$ 个顶点 $m$ 条边的无向连通图 $G$，顶点依次以 $1, 2, \dots, n$ 编号。$G$ 有以下特殊的性质：

* $G$ 中的每条边至多属于一个简单环。
* $G$ 中没有重边与自环。

简单环是指环中顶点互不相同，且不经过重复边的回路。

请你求出 $G$ 的不同生成树的数量。两棵生成树不同，当且仅当存在一条边在其中一棵生成树中出现，而不在另一棵生成树中出现。

由于答案可能很大，你只要求出答案对 $998244353$ 取模的结果。

### 输入格式

第一行，两个正整数 $n, m$，分别表示 $G$ 的顶点数与边数。

接下来 $m$ 行，每行两个整数 $u_i, v_i$，表示一条连接顶点 $u_i, v_i$ 的无向边。

### 输出格式

输出一行，一个整数，表示 $G$ 的不同生成树的数量对 $998244353$ 取模的结果。

### 输入输出样例

#### 输入 #1

```text
7 8
1 2
2 3
3 1
3 4
4 5
5 6
6 7
7 4
```

#### 输出 #1

```text
12
```

#### 输入 #2

```text
5 4
1 2
1 3
2 4
2 5
```

#### 输出 #2

```text
1
```

### 说明/提示

#### 数据范围

对于 $40\%$ 的测试点，保证 $1 \le n \le 8$，$1 \le m \le 10$。

对于 $60\%$ 的测试点，保证 $1 \le n \le 2000$，$1 \le m \le 2000$。

对于所有测试点，保证 $1 \le n \le 10^5$，$1 \le m \le 10^5$，$1 \le u_i, v_i \le n$。

### 题目分析与解题思路

#### 1. 仙人掌图（Cactus Graph）的核心性质
- **图论定义**：题目给定的是一张无向连通图，且明确指出“**每条边至多属于一个简单环，无重边和自环**”。在图论中，这种特殊的拓扑结构被称为**仙人掌图（Cactus Graph）**（也常译作细颈瓶图）。
- **边不相交特征**：仙人掌图最核心的结构特征在于：**任意两个简单环之间，绝对不会共享公共边**！也就是说，图中的每条边要么恰好属于 1 个简单环，要么完全不属于任何环（后者即为图论中的**桥/割边（Bridge）**）。两个环如果相交，至多只能相交于单个公共顶点（点仙人掌）。

#### 2. 生成树的本质与“破环选边”原理
- **生成树的定义**：对于包含 $n$ 个顶点的无向连通图，其生成树是包含全部 $n$ 个顶点、恰有 $n-1$ 条边且无环的连通无向图。
- **割边的唯一性（必须全选）**：
  - 如果一条边不属于任何简单环（即桥边），删去该边会导致整张图分裂为两个互不连通的子图。
  - 因此，所有非环边（桥边）**在任何一棵合法的生成树中都必须被保留**，其选边方案数为 $1$。
- **简单环的独立破环（必须且仅能破坏一条边）**：
  - 设图中有某个长度为 $L$ 的简单环（包含 $L$ 个顶点和 $L$ 条边）。
  - 若在环上保留全部 $L$ 条边，则图中必然包含回路，违背树的无环定义；
  - 若在环上删去 $2$ 条或更多边，则该环所在的局部连通块将被切断，破坏全图连通性；
  - 因此，为了破坏环路并保持全局连通，**必须且只能恰好删去环上的某一条边**，其余 $L-1$ 条边保留在生成树中。
  - 由于环上有 $L$ 条边，删去任意一条都能得到一条合法的生成树路径，因此该环**恰好有 $L$ 种互相独立的选边方案**。

#### 3. 乘法原理（Multiplication Principle）方案统计
- **环与环之间的独立性**：因为仙人掌图的各个简单环之间边互不相交，在环 $A$ 中删去哪条边，**丝毫不会影响**环 $B$ 的边集与连通状态。各个环的破环决策完全互相独立。
- **方案总数计算**：
  根据组合数学中的乘法原理，整张仙人掌图的不同生成树总数，严格等于**所有简单环长度的乘积**：
  $$\text{生成树数量} = \prod_{C \in \text{Cycles}} |C| \pmod{998244353}$$
  若图中本身是一棵树（无任何简单环），则乘积项为空，生成树数量自然为初始值 $1$。

#### 4. 算法设计：基于 DFS 树与返祖边的高效环检测
- **DFS 搜索树的性质**：
  - 在无向图的深度优先搜索（DFS）中，边被严格划分为**树边（Tree Edge）**与**非树边（Back Edge，返祖边）**；
  - 无向图的 DFS 搜索树**不存在横叉边（Cross Edge）**，非树边必定连接着当前遍历节点 $u$ 与其在搜索树上的某个祖先节点 $v$。
- **环长计算**：
  - 当从节点 $u$ 出发访问到邻接点 $v$ 时，若 $v$ 已经被访问过且不是 $u$ 的搜索树父节点，则 $(u, v)$ 构成一条返祖边；
  - 这条返祖边与搜索树上从 $v$ 到 $u$ 的树边路径恰好闭合成一个简单环；
  - 环包含的顶点数/边数即为两节点的深度差加 1：
    $$L = depth[u] - depth[v] + 1$$
  - 为避免一条无向返祖边被其两个端点各扫描一次导致重复连乘，我们约定**只在深度较深的一侧（即 $depth[u] > depth[v]$）触发计算**。
- **复杂度分析**：
  - **时间复杂度**：只需一次标准的 DFS 线性遍历，每个顶点和每条边仅访问常数次，时间复杂度为 $\mathcal{O}(n + m)$。对于 $n, m \le 10^5$ 的数据规模，运行耗时不超过 0.05 秒。
  - **空间复杂度**：邻接表 `adj`、深度数组 `depth_arr` 及访问标记数组 `visited` 占用 $\mathcal{O}(n + m)$ 内存空间，约 15MB，远低于评测环境 512MB 限制。

---

### 易错点与边界防坑指南

1. **父节点回退过滤**：无向图存储为双向边，DFS 遍历时如果遇到直接父节点 `v == p`，必须 `continue` 忽略，否则会将单条无向树边误判为长度为 2 的假环。
2. **取模防溢出**：在环长连乘过程中，必须使用 `long long` 存储中间答案，且每次乘法后立即对 $998244353$ 取模，防止中间结果超出 32 位整型上限。
3. **原图无环边界**：如果原图本身就是一棵树（$m = n - 1$），DFS 不会探测到任何返祖边，答案保持初始值 $1$，完全符合只有 1 棵生成树的客观事实。

### 完整参考代码 (C++11)

```cpp
/**
 * 题目: 【GESP真题】GESP八级 / CSP-S 题解：luogu-P17461 [GESP202609 八级] 生成树计数
 * 题号: P17461
 * 归属: CCF GESP 2026年9月认证 C++ 八级 / CSP-S
 * 考点: 仙人掌图性质、DFS 搜索树返祖边环检测、乘法原理
 * 复杂度: 时间 O(n + m), 空间 O(n + m)
 * 博客: https://www.coderli.com/gesp-8-luogu-p17461-cactus-spanning-tree/
 * 标准: C++11 (CCF GESP 官方大纲规范)
 */

#include <iostream>
#include <vector>

using namespace std;

// 常量定义：顶点与边数最大上限 10^5，题目指定的模数 998244353
const int MAXN = 100005;
const int MOD = 998244353;

// 邻接表存图：adj[u] 存储与顶点 u 相邻的所有顶点编号
vector<int> adj[MAXN];

// depth_arr[u] 记录节点 u 在 DFS 搜索树中的深度（根节点深度设为 1）
int depth_arr[MAXN];

// visited[u] 标记节点 u 在深度优先遍历中是否已被访问过
bool visited[MAXN];

// ans 存储生成树总方案数，初始化为 1（若原图无环则答案为 1）
long long ans = 1;

/**
 * 深度优先搜索（DFS）遍历无向图，检测简单环并统计方案数
 * @param u 当前正在访问的节点编号
 * @param p 当前节点在 DFS 搜索树中的直接父节点编号（避免双向边走回头路）
 * @param d 当前节点在 DFS 树中的深度
 */
void dfs(int u, int p, int d) {
    depth_arr[u] = d;     // 记录当前节点的搜索深度
    visited[u] = true;    // 标记当前节点已访问

    // 遍历当前节点 u 的所有相邻邻接点
    for (int v : adj[u]) {
        // 如果邻接点是搜索树上的父节点，说明是同一条无向树边的反向边，直接跳过
        if (v == p) continue;

        if (visited[v]) {
            // 如果邻接点 v 已经被访问过，说明遇到了一条返祖边（Back-edge）
            // 在无向图的 DFS 搜索树中，返祖边一定连接着当前节点与其祖先节点
            // 为避免一条无向边被两端各扫描一次导致重复计算，只在较深的一端（depth[v] < depth[u]）计算环长
            if (depth_arr[v] < depth_arr[u]) {
                // 环上的边数（即环长）等于两端点的深度差加 1
                int cycle_len = depth_arr[u] - depth_arr[v] + 1;
                // 根据乘法原理，消除该环必须且仅能删去环上 1 条边，有 cycle_len 种选择
                ans = (ans * cycle_len) % MOD;
            }
        } else {
            // 邻接点未被访问过，说明 (u, v) 是一条树边，沿着该边继续深入递归
            dfs(v, u, d + 1);
        }
    }
}

int main() {
    int n, m;
    // 读入顶点数 n 和边数 m
    cin >> n >> m;

    // 读入 m 条无向边并构建邻接表
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 从 1 号顶点作为根节点启动 DFS，父节点记为 0，初始深度从 1 开始
    dfs(1, 0, 1);

    // 输出不同生成树的数量对 998244353 取模后的结果
    cout << ans << endl;

    return 0;
}
```
