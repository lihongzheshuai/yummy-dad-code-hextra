在序列维护与动态统计问题中，区间修改与单点查询是一对经典的操作矛盾：朴素数组方案虽然能够以 $O(1)$ 的高速常数读取任意单个位置的数值，但在面对区间 $[x, y]$ 的批量累加修改时，必须逐个遍历修改区间内的每个元素，单次操作开销高达 $O(n)$；若直接套用标准树状数组（BIT）维护原序列，虽然能以 $O(\log n)$ 完成单点更新与区间和统计，但要实现区间修改依然需要调用 $(y - x + 1)$ 次单点修改，单次操作最坏退化至 $O(n \log n)$。当序列长度 $n$ 与操作指令总数 $m$ 双双达到 $5 \times 10^5$ 规模时，前述朴素思路均会导致总运算步数突破 $2.5 \times 10^{11}$ 次而导致严重超时（TLE）。洛谷 P3368「【模板】树状数组 2」是 CCF GESP 八级与 CSP-S 组别中关于数据结构对偶转化与思维跃迁的核心经典题目。本题的核心突破口在于**将差分（Difference Array）思想与树状数组（Binary Indexed Tree / Fenwick Tree）有机融合**：利用差分数组将原数组的「区间修改」巧妙转化为差分序列上的「两点单点修改」，并将原数组的「单点查询」转化为差分序列的「前缀和查询」，从而仅需极其精炼的代码与线性空间，将两种操作的时间复杂度完美均摊至 $O(\log n)$。题目洛谷官方难度评级为`普及+/提高-`。

## luogu-P3368 【模板】树状数组 2

> 🔗 **洛谷原题传送门**：[luogu-P3368 【模板】树状数组 2](https://www.luogu.com.cn/problem/P3368)

### 题目描述

如题，已知一个数列，你需要进行下面两种操作：

1. 将某区间每一个数加上 $x$；

2. 求出某一个数的值。

## 输入格式


第一行包含两个整数 $N$、$M$，分别表示该数列数字的个数和操作的总个数。

第二行包含 $N$ 个用空格分隔的整数，其中第 $i$ 个数字表示数列第 $i $ 项的初始值。

接下来 $M$ 行每行包含 $2$ 或 $4$个整数，表示一个操作，具体如下：

操作 $1$： 格式：`1 x y k` 含义：将区间 $[x,y]$ 内每个数加上 $k$；

操作 $2$： 格式：`2 x` 含义：输出第 $x$ 个数的值。

## 输出格式

输出包含若干行整数，即为所有操作 $2$ 的结果。

## 样例 #1

### 样例输入 #1
```text
5 5
1 5 4 2 3
1 2 4 2
2 3
1 1 5 -1
1 3 5 7
2 4
```

### 样例输出 #1

```text
6
10
```

### 题目深度剖析

#### 1. 经典困境的逆向思考：从「单点改+区间查」到「区间改+单点查」

在上一题洛谷 P3374「【模板】树状数组 1」中，我们解决的是**单点增加**与**区间求和**，这是标准树状数组最直接的应用场景：
- 原数组 $a$ 的单点更新：$O(\log n)$；
- 原数组 $a$ 的前缀和查询：$O(\log n)$，进而利用前缀和相减得到区间和。

而在本题 P3368 中，操作要求恰好发生对偶置换：
- **操作 1**：将区间 $[x, y]$ 内的每一个数全部增加 $k$（区间修改）；
- **操作 2**：查询第 $x$ 个数的当前数值（单点查询）。

如果仍然让树状数组直接维护原数组 $a[i]$：
- 单点查询极其简单，由于 $a[x] = S(x) - S(x - 1)$，两次前缀和查询耗时 $O(\log n)$；
- 但区间修改需要对 $i \in [x, y]$ 的每一个位置都调用一次 `update(i, k)`，最坏情况下区间长度为 $n$，单次修改耗时高达 $O(n \log n)$，在 $m = 5 \times 10^5$ 时完全不可接受。

此时必须引入序列处理中的核心数学工具——**差分序列**。

#### 2. 差分数组的数学骨架与前缀还原原理

设原始数列为 $a[1], a[2], \dots, a[n]$。定义该数列的**一阶差分序列** $d[1], d[2], \dots, d[n]$ 如下：
$$d[1] = a[1]$$
$$d[i] = a[i] - a[i - 1] \quad (2 \le i \le n)$$

差分序列具备以下两个极其优雅的数学对偶性质：

##### 性质一：差分序列的前缀和恰好还原原序列的单点数值
将差分序列从 $1$ 到 $x$ 累加求和：
$$\sum_{i = 1}^{x} d[i] = d[1] + (a[2] - a[1]) + (a[3] - a[2]) + \dots + (a[x] - a[x - 1])$$
观察该式的展开项，中间的所有相邻项发生正负抵消（裂项相消），最终结果恰为：
$$\sum_{i = 1}^{x} d[i] = a[x]$$
这意味着：**原序列中任意单点 $x$ 处的值，等价于其差分序列在前缀区间 $[1, x]$ 上的累加和！**

##### 性质二：原序列的区间增量修改转化为差分序列上的两次单点修改
假设需要将原序列区间 $[x, y]$ 内的所有元素全部加上增量 $k$：
- 对于位置 $i = x$：由于 $a[x]$ 增加了 $k$，而 $a[x - 1]$ 保持不变，因此新的差分值 $d[x]' = (a[x] + k) - a[x - 1] = d[x] + k$；
- 对于区间内部位置 $i \in (x, y]$：$a[i]$ 与 $a[i - 1]$ 同步增加了 $k$，新的差分值 $d[i]' = (a[i] + k) - (a[i - 1] + k) = d[i]$，差分值完全不变；
- 对于位置 $i = y + 1$（若 $y + 1 \le n$）：$a[y + 1]$ 保持不变，而 $a[y]$ 增加了 $k$，因此新的差分值 $d[y + 1]' = a[y + 1] - (a[y] + k) = d[y + 1] - k$；
- 对于位置 $i > y + 1$：$a[i]$ 与 $a[i - 1]$ 均未发生变化，差分值保持不变。

综上所述，原序列上的一整个区间的批量修改，在差分序列上**仅导致两个孤立点的位置发生突变**：
$$d[x] \leftarrow d[x] + k$$
$$d[y + 1] \leftarrow d[y + 1] - k \quad (\text{当 } y + 1 \le n)$$

#### 3. 树状数组维护差分序列的系统架构

对比上述性质与树状数组的标准能力：
1. **原序列的单点查询 $a[x]$** $\Longleftrightarrow$ **差分序列的前缀和 $\sum_{i=1}^x d[i]$**；
2. **原序列的区间修改 $[x, y] + k$** $\Longleftrightarrow$ **差分序列的两次单点修改 $d[x] + k$ 与 $d[y + 1] - k$**。

我们惊奇地发现：只要我们**用树状数组去存储和维护差分序列 $d$**，那么：
- 每次「区间修改」转化为树状数组的两次单点增量修改：调用 `update(x, k)` 和 `update(y + 1, -k)`，耗时为 $2 \times O(\log n) = O(\log n)$；
- 每次「单点查询」转化为树状数组对位置 $x$ 的一次前缀和查询：调用 `query_prefix(x)`，耗时为 $O(\log n)$！

这样，原本棘手的区间修改与单点查询问题，被极为巧妙地转换回了树状数组最擅长的基本盘上，两者复杂度均稳定在对数阶。

#### 4. 边界处理与关键防坑指南

1. **数值范围与数据类型**：
   - 题目保证任意时刻序列中元素的绝对值不超过 $2^{30} \approx 1.07 \times 10^9$；
   - 但在经过多次区间修改后，累加和与差分值可能突破 32 位有符号整型上限，且为了彻底规避可能的溢出风险，树状数组存储数组 `tree` 以及增量变量 `k`、累加和 `sum` 必须统一使用 64 位整型 `long long`。
2. **右端点越界防范**：
   - 当区间修改的右端点 $y = n$ 时，$y + 1 = n + 1 > n$；
   - 树状数组的有效管辖下标范围为 $[1, n]$，因此在执行右端点差分修正时，必须加入 `if (y + 1 <= n)` 判断，防止访问越界破坏内存。
3. **建树初始化优化**：
   - 初始读入序列时，可以直接通过相邻项之差 $a[i] - a[i - 1]$ 算出差分值，随后调用 `update(i, a[i] - a[i - 1])` 插入树状数组，建树时间为 $O(n \log n)$，在 $n = 5 \times 10^5$ 时耗时不足 0.05 秒。
4. **CCF 考纲与 C++11 规范**：
   - 遵循规范，严禁使用非标准的流加速语句，输入采用标准 `cin` 读取，逻辑清晰自洽。

### 规范 C++11 源码实现

```cpp
/**
 * 题目: 【GESP/CSP练习】GESP八级 / CSP-S 题解：luogu-P3368 【模板】树状数组 2
 * 题号: P3368
 * 归属: GESP八级 / CSP-S / 高级数据结构·差分树状数组模板题
 * 博客: https://www.coderli.com/gesp-8-luogu-p3368/
 * 标准: C++11 (严格遵循 CCF GESP 官方规范)
 */

#include <iostream>

using namespace std;

// 最大序列长度
const int MAXN = 500005;

// 数列长度 n 与操作次数 m
int n, m;

// 树状数组存储数组，维护原数列的一阶差分序列 d[i]
// 采用 long long 类型防止多次修改累加导致数值溢出
long long tree[MAXN];

/**
 * 计算低位二进制权值 lowbit(x)
 * 返回 x 在二进制表示下最低位的 1 及其后所有 0 构成的数值
 * 利用计算机补码特性：-x = ~x + 1，因此 x & (-x) 即为最低位的二进制权值
 * @param x 正整数索引
 * @return 最低位二进制权值
 */
int lowbit(int x) {
    return x & (-x);
}

/**
 * 树状数组单点增量更新
 * 将差分序列中位置 x 处的权值增加 val
 * 沿树状数组向根部逐层跃迁，更新所有覆盖该位置的管辖区间节点
 * @param x 差分序列下标（1-indexed）
 * @param val 增加的增量值
 */
void update(int x, long long val) {
    for (; x <= n; x += lowbit(x)) {
        tree[x] += val;
    }
}

/**
 * 树状数组前缀和查询
 * 计算差分序列区间 [1, x] 的前缀和
 * 由一阶差分性质可知，差分序列的前缀和恰好还原为原序列位置 x 处的真实值
 * @param x 前缀终止下标（1-indexed）
 * @return 差分序列前缀和（即原序列位置 x 的当前数值）
 */
long long query_prefix(int x) {
    long long sum = 0;
    for (; x > 0; x -= lowbit(x)) {
        sum += tree[x];
    }
    return sum;
}

/**
 * 区间增量修改操作
 * 将原序列区间 [x, y] 内所有元素加上 k
 * 根据差分原理，原序列区间加操作等价于在差分序列中：
 * 位置 x 加上 k，位置 y + 1 减去 k
 * @param x 区间起始下标（1-indexed）
 * @param y 区间终止下标（1-indexed）
 * @param k 增加的数值
 */
void range_add(int x, int y, long long k) {
    update(x, k);
    if (y + 1 <= n) {
        update(y + 1, -k);
    }
}

int main() {
    cin >> n >> m;

    long long prev = 0;
    // 读入初始序列元素，直接差分后插入树状数组
    for (int i = 1; i <= n; ++i) {
        long long current;
        cin >> current;
        // 计算相邻差分值 d[i] = a[i] - a[i - 1] 并更新到树状数组中
        update(i, current - prev);
        prev = current;
    }

    // 处理 m 次操作指令
    for (int i = 0; i < m; ++i) {
        int opt;
        cin >> opt;
        if (opt == 1) {
            int x, y;
            long long k;
            cin >> x >> y >> k;
            range_add(x, y, k);
        } else if (opt == 2) {
            int x;
            cin >> x;
            cout << query_prefix(x) << "\n";
        }
    }

    return 0;
}
```

### 算法复杂度全面分析

1. **时间复杂度分析**：
   - **单点增量更新 `update(x, val)`**：每次循环下标沿二进制低位递增 $\text{lowbit}(x)$，在 $[1, n]$ 范围内至多迭代 $\lceil \log_2 n \rceil$ 次，单次耗时严格为 $O(\log n)$；
   - **差分建树过程**：读入 $n$ 个初始元素，每个元素计算相邻差值后调用一次 `update`，建树总时间复杂度为 $O(n \log n)$；
   - **区间修改 `range_add(x, y, k)`**：单次区间修改转化为至多两次树状数组单点增量更新，总耗时为 $2 \times O(\log n) = O(\log n)$；
   - **单点查询 `query_prefix(x)`**：单次前缀和查询在循环中不断减去 $\text{lowbit}(x)$，至多迭代 $\lceil \log_2 n \rceil$ 次，单次查询耗时严格为 $O(\log n)$；
   - **整体时间复杂度**：处理 $m$ 次混合操作与 $n$ 个初始元素，整体运行时间复杂度为 $O((n + m) \log n)$。代入题目上限 $n, m = 5 \times 10^5$，$\log_2(5 \times 10^5) \approx 19$，总计算步数约为 $1.9 \times 10^7$ 次，加上平直循环无额外复杂函数调用的极小常数因子，可在 1.0 秒时限内高速通过。

2. **空间复杂度分析**：
   - **状态存储数组**：树状数组维护差分序列的累加权值，仅需开辟一个大小为 $n + 1$ 的一维长整型数组 `tree[MAXN]`；
   - **内存实际占用**：$500005 \times 8 \text{ 字节} \approx 4.0 \text{ MB}$；
   - **整体空间复杂度**：严格为 $O(n)$ 线性空间，相比于线段树通常需要开辟的 $4n$ 节点结构体空间，树状数组在空间效率与缓存局部性（Cache Locality）上具备极强优势，远低于题目给定的 125.00 MB 空间限制。
