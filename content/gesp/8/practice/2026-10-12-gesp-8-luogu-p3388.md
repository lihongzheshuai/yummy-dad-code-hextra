在网络拓扑与通信基础设施分析中，评估图的联通健壮性与识别单点故障（Single Point of Failure, SPOF）是核心课题。对于给定的无向图 $G = (V, E)$，若移去某顶点 $u$ 及其关联的所有边后，图的连通分量数严格增加，则称顶点 $u$ 为图的一个**割点（Cut Vertex / 割顶 / Articulation Point）**。朴素的割点判定方法通过枚举每个顶点并在图中将其暂时剔除，随后使用 BFS 或 DFS 重新验证其余节点的连通性，全图判定时间复杂度高达 $O(n \times (n + m))$。当点数 $n = 2 \times 10^4$、边数 $m = 10^5$ 时，总运算量达 $2 \times 10^9$ 次，必然导致严重超时（TLE）。洛谷 P3388「【模板】割点（割顶）」作为 CCF GESP 八级与 CSP-S 组别中无向图联通性领域最具代表性的基石模板题，确立了由 Robert Tarjan 提出的 **基于深度优先搜索树的 Tarjan 割点判定算法**。该算法巧妙引入「时间戳 $dfn$」与「追溯值 $low$」，仅需对全图进行单次线性深度优先搜索遍历，即可在 $O(n + m)$ 的最优时间复杂度内精准找出全图的所有割点。题目洛谷官方难度评级为`普及+/提高`。

## luogu-P3388 【模板】割点（割顶）

> 🔗 **洛谷原题传送门**：[luogu-P3388 【模板】割点（割顶）](https://www.luogu.com.cn/problem/P3388)

## 题目背景

割点

## 题目描述

给出一个 $n$ 个点，$m$ 条边的无向图，求图的割点。

## 输入格式

第一行输入两个正整数 $n,m$。

下面 $m$ 行每行输入两个正整数 $x,y$ 表示 $x$ 到 $y$ 有一条边。

## 输出格式

第一行输出割点个数。

第二行按照节点编号从小到大输出节点，用空格隔开。

## 样例 #1

### 样例输入 #1

```
6 7
1 2
1 3
1 4
2 5
3 5
4 5
5 6
```

### 样例输出 #1

```
1
5
```

## 提示

对于全部数据，$1\leq n \le 2\times 10^4$，$1\leq m \le 1 \times 10^5$。

点的编号均大于 $0$ 小于等于 $n$。

**Tarjan 图不一定联通。**

### 题目深度剖析

#### 1. 割点的图论本质与网络拓扑脆弱性
在无向图 $G = (V, E)$ 中，若存在两个相异顶点 $x, y \neq u$，使得 $x$ 到 $y$ 的所有简单路径均必须经过顶点 $u$，则移除 $u$ 必然导致 $x$ 与 $y$ 之间不再连通。这类关键节点在路由网络中是潜在的通信咽喉，在物理拓扑中是系统可靠性的瓶颈。
朴素暴力删点法每一次判定都需要全局遍历，抛弃了图在搜索过程中展现出的层次结构与回溯特性。Tarjan 算法的核心突破在于：通过深度优先搜索将无向图转化为一棵**深度优先搜索生成树（DFS Spanning Tree）**，并将非树边（在此为返祖边 / Back Edge）作为环路连接信息，实现了局部子树可达性的代数化表示。

#### 2. DFS 搜索树中的两类边与连通特性
在无向图上运行深度优先搜索时，图中的所有边被严格划分为两类：
1. **树边（Tree Edge）**：在 DFS 遍历过程中，首次访问未标记节点所经过的边。所有树边构成了以 DFS 搜索起点为根的生成树。
2. **返祖边（Back Edge / 后向边）**：连接当前节点与其在 DFS 树中的某个非直接父节点的祖先节点的边。注意：无向图中不存在横叉边（Cross Edge），因为任何未被树边覆盖的相邻节点，在 DFS 的深度优先推进机制下必然形成祖先后代关系。

返祖边的存在为后代节点提供了「不经过直接父节点即可跨越回溯到更高层祖先」的旁路跳板。因此，一个子节点及其子树能否在父节点被切断后依然与外部保持连通，完全取决于该子树内部是否存在指向父节点之上更高祖先的返祖边。

#### 3. 时间戳 $dfn$ 与追溯值 $low$ 的数学定义
为了量化这种「跨越回溯能力」，Tarjan 算法为每个节点维护两个核心量：
- **访问时间戳 $dfn[u]$（Depth-First Number）**：记录节点 $u$ 在整个 DFS 遍历流程中首次被访问时的逻辑时钟序号。$dfn$ 值越小，表示该节点在 DFS 树中的层级越靠上（越接近根部）。
- **追溯值 $low[u]$**：定义为节点 $u$ 及其在 DFS 树中的整棵子树内的所有节点，通过**至多一条返祖边**所能到达的节点的最小 $dfn$ 值。其严格数学递推式为：
  $$low[u] = \min \begin{cases} dfn[u], \\ low[v] & (u, v) \text{ 为树边（即 } v \text{ 为 } u \text{ 在 DFS 树中的子节点）}, \\ dfn[v] & (u, v) \text{ 为返祖边且 } v \neq fa[u] \end{cases}$$

#### 4. 割点判定准则的分类证明
基于 $dfn$ 与 $low$ 的定义，我们可以对节点 $u$ 是否为割点进行完备的分类讨论：

##### （1）非根节点（Non-root Node）的判定准则
若节点 $u$ 不是当前连通块的 DFS 搜索树根节点（即 $fa[u] \neq 0$）：
- 若 $u$ 存在至少一个子节点 $v$，满足：
  $$low[v] \ge dfn[u]$$
- **充要性分析**：$low[v] \ge dfn[u]$ 意味着以 $v$ 为根的整棵子树中，没有任何一条返祖边能够越过 $u$ 连接到 $dfn$ 小于 $dfn[u]$ 的更早祖先节点。因此，从子树 $v$ 通往树上其他祖先节点的唯一路径必须经过 $u$。一旦将 $u$ 移除，子树 $v$ 将与 $u$ 的所有祖先节点彻底断连，连通分量数量增加。故 **$u$ 必为割点**。
- 反之，若对于 $u$ 的所有子节点 $v$ 均有 $low[v] < dfn[u]$，则说明每个子树都能通过返祖边绕过 $u$ 连通至 $u$ 的祖先，移除 $u$ 不会破坏其连通性，此时 $u$ 不是割点。

##### （2）根节点（Root Node）的判定准则
若节点 $u$ 是当前连通块的 DFS 搜索树根节点（即 $fa[u] == 0$）：
- 根节点本身没有更早的祖先节点，上述 $low[v] \ge dfn[u]$ 条件对于根节点的所有子节点总是平凡成立的（因为 $dfn[root] = 1$，所有 $low[v] \ge 1$）。
- 因此不能套用非根节点的准则。根节点的判定定理为：**当且仅当根节点在 DFS 树中拥有至少两个独立的子树分支（即搜索树上的度数 $\ge 2$）时，根节点才是割点**。
- **充要性分析**：由于无向图的 DFS 树不存在横叉边，根节点的两个不同子树分支 $T_1$ 与 $T_2$ 之间绝不可能存在任何直接相连的边（否则在遍历 $T_1$ 时就会直接进入 $T_2$，使其合并为同一个子树）。因此，$T_1$ 与 $T_2$ 之间的所有连通路径均必须途径根节点 $u$。移除根节点后，$T_1$ 与 $T_2$ 必然相互分离。反之，若根节点仅有 $1$ 个子树分支，移除根节点后仅剩该子树自身，连通分量总数不增反减（减少 $1$），故不是割点。

#### 5. 易错点与工程防御
1. **图不一定连通（森林处理）**：题目说明中加粗标明「Tarjan 图不一定联通」。因此主函数中必须在外层循环遍历 $i \in [1, n]$，对每一个 `!dfn[i]` 的连通块分别调用 `tarjan(i, 0)`。
2. **割点重复标记防御**：同一个节点 $u$ 可能存在多个子节点 $v$ 均满足 $low[v] \ge dfn[u]$。若在满足条件时直接执行计数累加 `cnt++`，会导致同一割点被多次重复计数。正确做法是使用 `bool is_cut[MAXN]` 数组进行布尔标记，遍历结束后再统一汇总并按编号升序输出。
3. **返祖边与父节点的过滤**：在无向图中，双向边使得每个树边都有反向边通向父节点。在遍历 $u$ 的邻接点 $v$ 时，必须显式跳过父节点 `if (v == fa) continue;`，防止将树边误判为返祖边导致 $low[u]$ 被错误更新为 $dfn[fa]$。

### 详尽注释源码（C++11 标准）

```cpp
/**
 * 题目: 【GESP/CSP练习】GESP八级 / CSP-S 题解：luogu-P3388 【模板】割点（顶）
 * 题号: P3388
 * 归属: GESP八级 / CSP-S / 高级图论·Tarjan算法求无向图割点
 * 博客: https://www.coderli.com/gesp-8-luogu-p3388/
 * 标准: C++11 (严格遵循 CCF GESP 官方规范)
 */

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 最大顶点数常量定义
const int MAXN = 20005;

// 无向图邻接表
vector<int> adj[MAXN];

// dfn[u]: 记录节点 u 在 DFS 深度优先搜索遍历中的访问时间戳
int dfn[MAXN];

// low[u]: 记录节点 u 及其子树节点通过至多一条返祖边所能追溯到的最小时间戳
int low[MAXN];

// 全局逻辑时间戳递增计数器
int timer = 0;

// is_cut[u]: 标记节点 u 是否为割点，避免同一割点因满足多个子树条件而被重复统计
bool is_cut[MAXN];

/**
 * Tarjan 深度优先遍历算法求无向图割点
 * 
 * @param u 当前正在访问的图节点编号
 * @param fa 当前节点在 DFS 搜索树中的父节点编号（根节点的父节点传入 0）
 */
void tarjan(int u, int fa) {
    // 1. 初始化当前节点的访问时间戳和初始追溯值
    dfn[u] = low[u] = ++timer;
    int children = 0; // 记录节点 u 在 DFS 搜索树中的直接子树分支数量

    // 2. 遍历节点 u 的所有邻接边
    for (size_t i = 0; i < adj[u].size(); ++i) {
        int v = adj[u][i];

        // 忽略直接通往父节点的反向边
        if (v == fa) {
            continue;
        }

        if (!dfn[v]) {
            // 情况 A: 邻接节点 v 尚未被访问，(u, v) 为 DFS 搜索树上的树边 (Tree Edge)
            children++;
            tarjan(v, u);

            // 回溯时，利用子节点 v 的追溯能力更新当前节点 u 的追溯值
            low[u] = min(low[u], low[v]);

            // 判断非根节点是否为割点:
            // 若子节点 v 无法跨越 u 回溯到 u 的更早祖先 (low[v] >= dfn[u])，
            // 则切断 u 后，以 v 为根的子树将无法与外界联通，故 u 是割点
            if (fa != 0 && low[v] >= dfn[u]) {
                is_cut[u] = true;
            }
        } else {
            // 情况 B: 邻接节点 v 已经被访问过，(u, v) 为返祖边 (Back Edge)
            // 更新当前节点能追溯到的最早祖先时间戳
            low[u] = min(low[u], dfn[v]);
        }
    }

    // 判断 DFS 搜索树的根节点是否为割点:
    // 根节点没有祖先节点，当且仅当其在 DFS 树中拥有至少 2 个独立的子树分支时，
    // 移除根节点才会使这些子树分支相互孤立，故当 children >= 2 时根节点为割点
    if (fa == 0 && children >= 2) {
        is_cut[u] = true;
    }
}

int main() {
    int n, m;
    cin >> n >> m;

    // 读入 m 条无向边并构建邻接表
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 遍历所有节点：图可能由多个不相连的连通分量组成（森林）
    for (int i = 1; i <= n; ++i) {
        if (!dfn[i]) {
            // 以节点 i 为该连通分量 DFS 树的根节点，父节点设为 0
            tarjan(i, 0);
        }
    }

    // 统计割点总数
    int cut_count = 0;
    for (int i = 1; i <= n; ++i) {
        if (is_cut[i]) {
            cut_count++;
        }
    }

    // 输出第一行：割点总数
    cout << cut_count << "\n";

    // 输出第二行：按节点编号从小到大输出所有割点，用空格分隔
    bool first = true;
    for (int i = 1; i <= n; ++i) {
        if (is_cut[i]) {
            if (!first) {
                cout << " ";
            }
            cout << i;
            first = false;
        }
    }
    if (cut_count > 0) {
        cout << "\n";
    }

    return 0;
}
```

### 算法复杂度全面分析

1. **时间复杂度分析**：
   - **建图阶段**：读入 $m$ 条边并向邻接表中插入元素，时间复杂度为严格的 $O(m)$；
   - **Tarjan 遍历阶段**：整个算法由深度优先搜索驱动。由于采用了时间戳布尔标记 `dfn`，每个顶点 $u \in V$ 恰好被访问且仅被递归调用一次（$O(n)$）；
   - **边扫描与松弛**：在所有顶点的 DFS 遍历过程中，邻接表中的每一条有向边（共 $2m$ 条）恰好被遍历并检查一次（$O(m)$）；
   - **割点统计与输出**：遍历 $1$ 到 $n$ 的布尔标记数组并格式化输出，耗时严格为 $O(n)$；
   - **整体时间复杂度**：全流程总运行时间复杂度为严格线性的 $O(n + m)$。代入数据上限 $n = 2 \times 10^4$、$m = 10^5$，总基本操作运算步数仅约为 $2.4 \times 10^5$ 次，耗时在 $0.05$ 秒以内，以绝对优势远低于洛谷评测机 1.0 秒的时间限制。

2. **空间复杂度分析**：
   - **邻接表空间**：使用 `std::vector<int> adj[MAXN]` 存储双向边，包含 $n$ 个 vector 头以及存储 $2m$ 个整型元素，总动态内存开销约为 $2 \times 10^5 \times 4 \text{ 字节} \approx 0.8 \text{ MB}$；
   - **状态数组空间**：全局 `dfn`、`low` 数组大小均为 $MAXN = 20005$，占用静态内存 $20005 \times 4 \times 2 \approx 160 \text{ KB}$；`is_cut` 布尔数组占用约 $20 \text{ KB}$；
   - **系统递归调用栈**：在最坏情况下（图退化为单链），DFS 树的最大深度为 $n$，递归栈深度为 $O(n)$，单层栈帧仅消耗常数个局部变量，栈空间消耗小于 $2 \text{ MB}$；
   - **整体空间复杂度**：严格为 $O(n + m)$，程序峰值内存占用小于 $5 \text{ MB}$，完全符合甚至远低于常规 128 MB / 256 MB 的内存限制，极其紧凑且安全。
