将一串连续的乒乓球胜负记录分别按 $11$ 分制与 $21$ 分制还原出每一局的比分，洛谷 P1042「[NOIP 2003 普及组] 乒乓球」看似只是最基础的加分计数，实则是信奥赛场上检验**“真实赛制规则建模与极端边界防御”**的经典试金石。许多初学者在写这道题时频频痛失满分（只拿 $60 \sim 80$ 分），往往不是因为不会循环计数，而是掉进了三个极具迷惑性的规则细节陷阱：第一，误以为“某一方先到 $11$ 分（或 $21$ 分）即获胜”，忽略了乒乓球“追平后必须**净胜至少 $2$ 分**（$\max(w, l) \ge K$ 且 $|w - l| \ge 2$）”的加赛（Deuce）规则；第二，忽略了题干中加粗强调的**“当一局比赛结束后，下一局立刻开始”**——如果最后一个球恰好结束了当前局（例如连赢 $11$ 球后紧接着遇到终止符 `E`），此时新一局已经立即开启，必须额外输出一行 `0:0`（同理，若开局第一个字符就是 `E`，也必须输出 `0:0`）；第三，由于输出要求先完整打印 $11$ 分制结果、空一行后再打印 $21$ 分制结果，必须先将终止符 `E` 之前的全部有效字符离线存入字符串或数组中，再将分制阈值 $K \in \{11, 21\}$ 抽象为统一的状态机函数复用两遍。本题完美契合 CCF GESP 五级（多状态复杂模拟与字符串处理）及 CSP-J 普及组第一题的考察风格，洛谷官方难度评级为`普及−`。

## luogu-P1042 [NOIP 2003 普及组] 乒乓球

> 🔗 **洛谷原题传送门**：[luogu-P1042 [NOIP 2003 普及组] 乒乓球](https://www.luogu.com.cn/problem/P1042)

### 题目背景

国际乒联现在主席沙拉拉自从上任以来就立志于推行一系列改革，以推动乒乓球运动在全球的普及。其中 $11$ 分制改革引起了很大的争议，有一部分球员因为无法适应新规则只能选择退役。华华就是其中一位，他退役之后走上了乒乓球研究工作，意图弄明白 $11$ 分制和 $21$ 分制对选手的不同影响。在开展他的研究之前，他首先需要对他多年比赛的统计数据进行一些分析，所以需要你的帮忙。

### 题目描述

华华通过以下方式进行分析，首先将比赛每个球的胜负列成一张表，然后分别计算在 $11$ 分制和 $21$ 分制下，双方的比赛结果（截至记录末尾）。

比如现在有这么一份记录，（其中 $\texttt W$ 表示华华获得一分，$\texttt L$ 表示华华对手获得一分）：

$$\texttt{WWWWWWWWWWWWWWWWWWWWWWLW}$$

在 $11$ 分制下，此时比赛的结果是华华第一局 $11$ 比 $0$ 获胜，第二局 $11$ 比 $0$ 获胜，正在进行第三局，当前比分 $1$ 比 $1$。而在 $21$ 分制下，此时比赛结果是华华第一局 $21$ 比 $0$ 获胜，正在进行第二局，比分 $2$ 比 $1$。如果一局比赛刚开始，则此时比分为 $0$ 比 $0$。直到分差大于或者等于 $2$，才一局结束。

**注意：当一局比赛结束后，下一局立刻开始**。

你的程序就是要对于一系列比赛信息的输入（$\texttt{WL}$ 形式），输出正确的结果。

### 输入格式

每个输入文件包含若干行字符串，字符串由大写的 $\texttt W$ 、 $\texttt L$ 和 $\texttt E$ 组成。其中 $\texttt E$ 表示比赛信息结束，程序应该忽略 $\texttt E$ 之后的所有内容。

### 输出格式

输出由两部分组成，每部分有若干行，每一行对应一局比赛的比分（按比赛信息输入顺序）。其中第一部分是 $11$ 分制下的结果，第二部分是 $21$ 分制下的结果，两部分之间由一个空行分隔。

### 输入输出样例

#### 样例输入 #1
```text
WWWWWWWWWWWWWWWWWWWW
WWLWE
```

#### 样例输出 #1
```text
11:0
11:0
1:1

21:0
2:1
```

### 说明/提示

每行至多 $25$ 个字母，最多有 $2500$ 行。

**【管理员附注】**

本题为非常早期的试题，在测试点中出现了如下两个问题。在洛谷上这两个测试点的疏漏被保留：

1. 有一个测试点实际上有 $2501$ 行数据。
2. 有一个测试点的输入数据出现了非 $\texttt W$ 、 $\texttt L$ 和 $\texttt E$ 的字符，不符合输入格式的要求。不过这些字符只出现在 $\texttt E$ 字符之后，按题目要求忽略 $\texttt E$ 之后的全部字符即可。

### 题目深度剖析与核心解题模型

#### 1. 乒乓球赛制结束判定的充要条件

设当前局华华的得分为 $w$，对手的得分为 $l$，当前模拟的赛制目标分为 $K$（$K = 11$ 或 $K = 21$）。
什么时候当前这一局才算真正结束？必须**同时满足**以下两个条件：
1. **分数达标**：至少有一方得分达到或超过 $K$ 分，即：
   $$\max(w, l) \ge K \iff (w \ge K \lor l \ge K)$$
2. **分差达标**：双方的分差绝对值大于或等于 $2$ 分，即：
   $$|w - l| \ge 2$$

- **常见反例**：若当前比分为 $10:10$，华华再赢一球变为 $11:10$。此时虽然满足 $w \ge 11$，但分差 $|11 - 10| = 1 < 2$，比赛**并未结束**！必须继续打下去，直到出现如 $12:10$、$13:15$ 等分差达到 $2$ 分的时刻，这一局才宣告结束。

---

#### 2. 为什么“循环结束后无条件输出 `w:l`”能完美统合所有 `0:0` 边界？

题目中有两处非常关键的说明：
- *“如果一局比赛刚开始，则此时比分为 $0$ 比 $0$。”*
- *“**注意：当一局比赛结束后，下一局立刻开始**。”*

我们按时间顺序梳理单局状态机的流转过程：
1. 初始时，第一局比赛刚开始，比分为 $w = 0, l = 0$；
2. 每读入一个球（`W` 或 `L`），对应选手得分 $+1$；
3. 紧接着立刻检查是否满足“一局结束条件”（`(w >= K || l >= K) && abs(w - l) >= 2`）：
   - 若满足，则说明当前局刚刚分出胜负！我们立即输出这局的最终比分 `w:l`；
   - 根据“当一局比赛结束后，下一局立刻开始”，我们**立刻将比分重置为 `w = 0, l = 0`**，代表无缝进入下一局的初始状态！
4. 当所有球（截至 `E` 之前）全部遍历完毕后，当前手头的 `w` 和 `l` 代表什么？
   - **情况 A（常规未完局）**：比如打到 $1:1$ 遇到 `E`，此时正在进行中的这一局尚未结束，输出 `1:1`；
   - **情况 B（刚好打满一整局后遇到 `E`）**：比如输入是 `WWWWWWWWWWWE`（正好 $11$ 个 `W`）。在处理第 $11$ 个 `W` 时，触发局末判定输出了 `11:0`，随后立即重置 `w = 0, l = 0` 开启第二局。紧接着循环结束，此时在循环外再输出一次 `w:l`，就会自动输出第二局刚开始的 `0:0`！
   - **情况 C（空记录，开局直接遇到 `E`）**：循环一次都不执行，循环外直接输出初始的 `0:0`！

可以看到，**“局末立即输出并清零 + 循环结束后无条件输出当前 `w:l`”** 这一极简逻辑，无需任何特判 `if`，就将上述三种边界情况 $100\%$ 严丝合缝地统一了起来！

---

#### 3. 输入读取技巧与管理员附注防坑

观察题目说明中的【管理员附注】：
1. **行数超限风险**：原题说最多 $2500$ 行、每行 $25$ 个字母（约 $62500$ 字符），但实际有一个测试点有 $2501$ 行。如果用定长数组，建议至少开到 $70000$ 以上；或者直接使用 C++ 的动态字符串 `std::string` 追加字符，彻底免疫长度越界。
2. **换行符与 `E` 之后的非法字符**：输入跨越多行，且 `E` 之后可能含有奇奇怪怪的非法字符。
   - 如果使用 `while (cin >> ch && ch != 'E')` 逐字符读取：
   - `cin >> ch` 会自动跳过所有的空格、回车（`\r`）和换行符（`\n`）；
   - 一旦读到字符 `'E'`，循环条件 `ch != 'E'` 立即为假并终止读取，`'E'` 之后的所有字符（无论合法与否）全部被留在输入流中直接忽略，干净利落！

### 完整参考代码 (C++11)

```cpp
/**
 * Problem: luogu-P1042 [NOIP 2003 普及组] 乒乓球
 * Algorithm: 字符串存储与多赛制状态机模拟 (String Storage & Multi-Rule Simulation)
 * Standard: C++11 (CCF GESP 五级 / CSP-J 官方规范)
 * Blog: https://www.coderli.com/noip-2003-luogu-p1042/
 * Author: OneCoder
 */

#include <iostream>
#include <string>
#include <cmath>

using namespace std;

// 存储截至字符 'E' 之前的所有比赛胜负记录（'W' 或 'L'）
string records = "";

/**
 * 模拟并输出指定分制 target（11 分制或 21 分制）下的所有局比分
 * @param target 获胜所需的基础分数（11 或 21）
 */
void simulate(int target) {
    int w = 0; // 华华当前局的得分
    int l = 0; // 对手当前局的得分

    // 逐球遍历比赛记录
    for (size_t i = 0; i < records.length(); ++i) {
        if (records[i] == 'W') {
            w++;
        } else if (records[i] == 'L') {
            l++;
        }

        // 一局结束的判定条件：
        // 1. 至少有一方得分达到或超过 target（w >= target 或 l >= target）
        // 2. 双方分差的绝对值大于或等于 2（abs(w - l) >= 2）
        if ((w >= target || l >= target) && abs(w - l) >= 2) {
            cout << w << ":" << l << "\n";
            // 当一局比赛结束后，下一局立刻开始，双方比分清零
            w = 0;
            l = 0;
        }
    }

    // 关键边界：截至记录末尾，正在进行中的这一局（哪怕刚开局比分为 0:0）也必须输出
    cout << w << ":" << l << "\n";
}

int main() {
    char ch;
    // 逐字符读取输入（cin >> ch 会自动跳过空格和换行符）
    // 遇到比赛结束标志 'E' 时立即停止读取，忽略 'E' 之后的全部内容
    while (cin >> ch && ch != 'E') {
        if (ch == 'W' || ch == 'L') {
            records += ch;
        }
    }

    // 第一部分：输出 11 分制下的比赛结果
    simulate(11);

    // 两部分之间由一个空行分隔
    cout << "\n";

    // 第二部分：输出 21 分制下的比赛结果
    simulate(21);

    return 0;
}
```

### 复杂度分析与常见避坑指南

1. **时间与空间复杂度**：
   - **时间复杂度**：设有效比赛记录总球数为 $N$（$N \le 2501 \times 25 \approx 6.25 \times 10^4$）。读取耗时 $\mathcal{O}(N)$，随后 $11$ 分制和 $21$ 分制各线性扫描一遍字符串，总时间复杂度严格为 $\mathcal{O}(N)$，运行耗时不足 $5\text{ms}$。
   - **空间复杂度**：使用一个 `std::string` 存储有效字符，占用内存仅约 $64\text{KB}$，空间复杂度为 $\\mathcal{O}(N)$。
2. **避坑点 1：画蛇添足加了 `if (w != 0 || l != 0)` 才输出最后一局**：
   - 这是本题考场上失分率最高的错误！很多同学在循环结束后写了一句 `if (w > 0 || l > 0) cout << w << ":" << l;`。
   - 一旦加上这个判断，当输入只有一个 `'E'`，或者最后一球刚好以 `11:0` 结束一局时，新一局已经开始（比分为 `0:0`），你的程序就会漏掉这一行 `0:0` 的输出，直接在对应测试点上 WA！
3. **避坑点 2：按行读取并在发现 `'E'` 时直接 `break` 整行**：
   - 如果使用 `cin >> line` 每次读入一整行字符串，要注意字符 `'E'` **不一定出现在一行的开头**（例如样例中的 `WWLWE`，`'E'` 在行末）。如果发现该行包含 `'E'` 就直接跳过整行，会漏掉 `'E'` 前面的 `WWLW`；如果处理完 `'E'` 后忘了退出外层循环，又会继续读取后面的行。因此直接用 `while (cin >> ch && ch != 'E')` 按单字符流式读取是最稳妥的做法。
