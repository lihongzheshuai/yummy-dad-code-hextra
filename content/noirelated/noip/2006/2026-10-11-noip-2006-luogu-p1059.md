洛谷经典算法真题 P1059「[NOIP2006 普及组] 明明的随机数」，是信息学竞赛中几乎所有初学者接触“数据去重与排序”业务场景时的经典启蒙之作。本题完美契合 CCF GESP 四级考纲（基础排序、线性表操作与标记思想）以及 CSP-J 普及组入门练习。题目的核心需求非常直观：给定一批可能包含重复数字的正整数学号，要求剔除所有重复元素并按从小到大的顺序输出。由于本题设定的数据值域极小（$1 \le x \le 1000$ 且总数 $N \le 100$），使得它天然拥有两种各具魅力的解题范式：一是利用值域作为下标的**“布尔桶标记法（Bucket Flagging）”**，在常数级时间内完成去重并天然有序；二是竞赛选手最常用的**“STL 排序与双指针去重（std::sort + std::unique）”**。两种解法相映成趣，是夯实四级基础算法地基的绝佳标杆。题目难度评级为洛谷`入门`。

## luogu-P1059 [NOIP2006 普及组] 明明的随机数

> 🔗 **洛谷原题传送门**：[luogu-P1059 [NOIP2006 普及组] 明明的随机数](https://www.luogu.com.cn/problem/P1059)

### 题目描述

明明想在学校中请一些同学做一项问卷调查，为了实验的客观性，他先用计算机生成了 $N$ 个 $1$ 到 $1000$ 之间的随机整数（$N \le 100$），对于其中重复的数字，只保留一个，把其余相同的数去掉，不同的数对应着不同的学生的学号。然后再把这些数从小到大排序，按照排好的顺序去找同学做调查。

请你协助明明完成“去重”与“排序”的工作。

### 输入格式

共 $2$ 行。

第 $1$ 行为 $1$ 个正整数，表示所生成的随机数的个数：$N$。  
第 $2$ 行有 $N$ 个用空格隔开的正整数，为所生成的随机数。

### 输出格式

共 $2$ 行。

第 $1$ 行为 $1$ 个正整数 $M$，表示不相同的随机数的个数。  
第 $2$ 行为 $M$ 个用空格隔开的正整数，为从小到大排好序的不相同的随机数。

### 输入输出样例

#### 输入 #1
```text
10
20 40 32 67 40 20 89 300 400 15
```

#### 输出 #1
```text
8
15 20 32 40 67 89 300 400
```

### 说明/提示

【数据范围】  
- 对于 $100\%$ 的数据，满足 $1 \le N \le 100$，每个随机数都在 $1$ 到 $1000$ 之间（包含 $1$ 和 $1000$）。  
- NOIP2006 普及组第一题。

### 题目深度剖析与核心解题模型

#### 1. 核心矛盾：排序与去重的协同处理

很多编程初学者的第一直觉往往是：
1. 先开一个数组读入全部数字；
2. 双重循环检查是否有相同元素，找到重复项就将其从数组中移动删除；
3. 最后再用冒泡排序或者选择排序将剩下的元素从小到大排好。

这种朴素思路不仅代码冗长繁琐，而且在数组中做“元素删除”操作需要频繁后移元素，时间复杂度偏高（达到 $\mathcal{O}(N^2)$），极易因下标混乱导致边界 Bug。

事实上，面对“值域集中且较小”的去重排序问题，我们有更加优雅明朗的解决路径。

---

#### 2. 解法一：布尔桶标记法（推荐四级学员优先掌握）

##### （1）核心构思
题目中有一个至关重要的数据特征：**所有随机数的数值范围严格在 $[1, 1000]$ 之间**。  
值域上限仅仅只有 $1000$，这为我们提供了天然的“桶（Bucket）”思路：

1. 开辟一个大小为 $1005$ 的布尔数组（或整型数组）`bucket`，初始全为 $0$；
2. 每当读入一个数字 $x$ 时，直接查看 `bucket[x]`：
   - 若 `bucket[x] == 0`，说明这是 $x$ 第一次登场，将其置为 $1$（`bucket[x] = 1`），同时独立不同数字的计数器 `cnt++`；
   - 若 `bucket[x] == 1`，说明之前已经记录过该学号，无需任何操作，自动实现“去重”；
3. 读入完毕后，第一行直接输出计数器 `cnt`；
4. 第二行从下标 $v = 1$ 到 $1000$ 升序扫描整个数组：只要 `bucket[v] == 1` 就输出数值 $v$。因为下标 $v$ 天然是严格递增的，所以**扫描输出的过程天然就是排好序的**！

##### （2）时空开销
- **时间复杂度**：输入耗时 $\mathcal{O}(N)$，扫描输出耗时 $\mathcal{O}(V)$（其中 $V = 1000$ 为值域大小）。总时间复杂度为 $\mathcal{O}(N + V)$，在评测机上耗时不足 $1\text{ms}$；
- **空间复杂度**：仅需长度为 $1005$ 的辅助数组，空间占用不到 $4\text{KB}$，极其轻量。

---

#### 3. 解法二：STL 排序 + std::unique 去重（标准竞赛规范）

当未来面对数据范围更大（例如数值在 $[1, 10^9]$，无法直接开辟超大桶数组）的问题时，通用的工业级解法是“先排序、再去重”：

1. **先排序**：使用 `std::sort()` 将数组升序排列。排序后，所有重复的相同数值必然会在物理内存上相邻紧挨在一起；
2. **再去重**：利用 C++ 标准库提供的 `std::unique()` 算法。该函数通过双指针将所有相邻的重复项压到数组末尾，并返回指向去重后有效数据末尾的迭代器；
3. **输出结果**：有效区间的长度即为不重复数字的个数，遍历输出该有效区间即可。

---

### 完整参考代码 (C++11)

#### 版本一：布尔桶标记法（四级通俗易懂，推荐）

```cpp
/**
 * Problem: luogu-P1059 [NOIP2006 普及组] 明明的随机数
 * Algorithm: 桶标记法 (Bucket Flagging · 空间换时间天然有序)
 * Standard: C++11 (CCF GESP 四级 / CSP-J 官方规范)
 * Author: OneCoder
 */

#include <iostream>

using namespace std;

// bucket[x] 记录数值 x 是否出现过
// 数值范围 1 ~ 1000，数组大小开 1005 预留安全边界
int bucket[1005];

int main() {
    int n;
    cin >> n;

    int distinct_cnt = 0; // 记录不重复的随机数个数

    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        // 如果该数值之前未出现过，标记为已出现，且计数加 1
        if (bucket[x] == 0) {
            bucket[x] = 1;
            distinct_cnt++;
        }
    }

    // 第一行输出不重复的随机数总个数
    cout << distinct_cnt << "\n";

    // 第二行按照数值从小到大（下标 1 到 1000）依次扫描输出
    bool first = true;
    for (int v = 1; v <= 1000; ++v) {
        if (bucket[v] == 1) {
            if (!first) {
                cout << " ";
            }
            cout << v;
            first = false;
        }
    }
    cout << "\n";

    return 0;
}
```

#### 版本二：STL 容器与 `std::sort` + `std::unique`（高阶通用规范）

```cpp
/**
 * Problem: luogu-P1059 [NOIP2006 普及组] 明明的随机数
 * Algorithm: STL 升序排序与双指针去重 (sort + unique)
 * Standard: C++11 (CCF GESP 四级 / CSP-J 官方规范)
 * Author: OneCoder
 */

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    // 第一步：先对数组进行升序排序，使相同元素紧邻
    sort(a.begin(), a.end());

    // 第二步：使用 unique 将相邻重复元素剔除至末尾，并获取有效数据的新逻辑边界
    auto it = unique(a.begin(), a.end());

    // 计算去重后的互不相同的整数个数
    int m = it - a.begin();
    cout << m << "\n";

    // 第三步：输出去重并排序后的前 m 个元素
    for (int i = 0; i < m; ++i) {
        cout << a[i] << (i + 1 == m ? "\n" : " ");
    }

    return 0;
}
```
