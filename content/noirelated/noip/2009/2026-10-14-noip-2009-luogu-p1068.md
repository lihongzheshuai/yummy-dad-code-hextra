洛谷经典算法真题 P1068「[NOIP2009 普及组] 分数线划定」，以世博会志愿者选拔笔试为现实场景，是信息学竞赛中考查“结构体建模（struct）”、“多关键字自定义排序”以及“实际业务规则模拟（按比例划线与重分入围）”的标志性基础试题。本题完美契合 CCF GESP 四级考纲（多关键字排序、线性表操作）与 CSP-J 普及组入门练习。题目的核心需求是：根据计划录取人数的 $150\%$（向下取整）确定基准排名，并以该名次选手的笔试成绩作为面试分数线；所有成绩不低于该分数线的选手均进入面试，且入围选手需按成绩降序、成绩相同时按报名号升序输出。试题的关键在于精准把握两点：一是“分数线由基准名次确定，同分选手一律同权入围”带来的实际入围人数可能大于计划名额的业务逻辑；二是通过重载或自定义比较函数，优雅实现满足严格弱序（Strict Weak Ordering）的多条件排序。题目在洛谷的官方难度评级为`普及-`。

## luogu-P1068 [NOIP2009 普及组] 分数线划定

> 🔗 **洛谷原题传送门**：[luogu-P1068 [NOIP2009 普及组] 分数线划定](https://www.luogu.com.cn/problem/P1068)

### 题目描述

世博会志愿者的选拔工作正在 A 市如火如荼的进行。为了选拔最合适的人才，A 市对所有报名的选手进行了笔试，笔试分数达到面试分数线的选手方可进入面试。面试分数线根据计划录取人数的 $150\%$ 划定，即如果计划录取 $m$ 名志愿者，则面试分数线为排名第 $m \times 150\%$（向下取整）名的选手的分数，而最终进入面试的选手为笔试成绩不低于面试分数线的所有选手。

现在就请你编写程序划定面试分数线，并输出所有进入面试的选手的报名号和笔试成绩。

### 输入格式

第一行，两个整数 $n,m(5 \leq n \leq 5000,3 \leq m \leq n)$，中间用一个空格隔开，其中 $n$ 表示报名参加笔试的选手总数，$m$ 表示计划录取的志愿者人数。输入数据保证 $m \times 150\%$ 向下取整后小于等于 $n$。

第二行到第 $n+1$ 行，每行包括两个整数，中间用一个空格隔开，分别是选手的报名号 $k(1000 \leq k \leq 9999)$和该选手的笔试成绩 $s(1 \leq s \leq 100)$。数据保证选手的报名号各不相同。

### 输出格式

第一行，有 $2$ 个整数，用一个空格隔开，第一个整数表示面试分数线；第二个整数为进入面试的选手的实际人数。

从第二行开始，每行包含 $2$ 个整数，中间用一个空格隔开，分别表示进入面试的选手的报名号和笔试成绩，按照笔试成绩从高到低输出，如果成绩相同，则按报名号由小到大的顺序输出。

### 输入输出样例

#### 样例输入 #1
```
6 3 
1000 90 
3239 88 
2390 95 
7231 84 
1005 95 
1001 88
```

#### 样例输出 #1

```
88 5 
1005 95 
2390 95 
1000 90 
1001 88 
3239 88
```

### 提示

【样例说明】

$m \times 150\% = 3 \times150\% = 4.5$，向下取整后为 $4$。保证 $4$ 个人进入面试的分数线为 $88$，但因为 $88$ 有重分，所以所有成绩大于等于 $88$ 的选手都可以进入面试，故最终有 $5$ 个人进入面试。

### 题目深度剖析与核心解题模型

#### 1. 考点拆解与业务规则梳理

本题是典型的“现实业务规则模拟 + 数据结构化处理”题目，主要考查以下两个核心维度：

1. **结构体建模与多关键字排序**：
   - 每位选手具备两个紧密关联的属性：报名号 $k$ 和笔试成绩 $s$。在 C++ 中，最自然且符合工程规范的数据结构即为 `struct`；
   - 排序要求同时遵循两个优先级顺序：
     - **第一关键字（主要标准）**：成绩从高到低（降序）。
     - **第二关键字（次要标准）**：成绩相同时，报名号由小到大（升序）。
2. **比例截断与同分全额入围**：
   - 计划录取 $m$ 人，基准名额为 $\lfloor m \times 1.5 \rfloor$。在整数运算中，$\lfloor m \times 1.5 \rfloor$ 可直接通过 `m * 3 / 2` 精确计算，彻底避免浮点数精度风险；
   - **核心转折点**：基准名额对应的选手成绩即为“面试分数线”。但最终入围人员不是简单取前 $\lfloor m \times 1.5 \rfloor$ 人，而是**所有成绩 $\ge$ 分数线的选手**；
   - 因此，当分数线上存在多位同分选手时，实际进入面试的人数会严格大于基准名额（如样例中基准为 $4$ 人，实际入围 $5$ 人）。

---

#### 2. 多关键字排序比较函数设计

在 C++ 中使用 `std::sort` 对结构体容器进行排序时，自定义比较函数必须满足**严格弱序（Strict Weak Ordering）**原则：即当两个元素相等时，必须返回 `false`，绝不能出现 `<` 与 `>` 混淆导致死循环或运行时错误。

比较逻辑非常清晰：
- 若两人成绩不同（`a.score != b.score`），成绩更高者排在前面，返回 `a.score > b.score`；
- 若两人成绩相同，报名号较小者排在前面，返回 `a.id < b.id`。

代码实现简洁明了：
```cpp
bool cmp(const Candidate& a, const Candidate& b) {
    if (a.score != b.score) {
        return a.score > b.score;
    }
    return a.id < b.id;
}
```

---

#### 3. 算法全流程与时空复杂度分析

1. **输入阶段**：读入 $n, m$，依次读入每位选手的报名号与成绩，存储在 `vector<Candidate>` 或数组中。耗时 $\mathcal{O}(n)$；
2. **排序阶段**：调用 `std::sort(a.begin(), a.end(), cmp)`，对 $n$ 位选手进行多关键字排序。耗时 $\mathcal{O}(n \log n)$；
3. **划线阶段**：
   - 计算基准下标 `target_rank = m * 3 / 2`；
   - 下标从 $0$ 开始编号，第 `target_rank` 名对应的数组元素为 `a[target_rank - 1]`；
   - 确定分数线 `cutoff_score = a[target_rank - 1].score`；
4. **统计与输出**：
   - 从第 $0$ 个选手开始向后扫描，直到成绩小于 `cutoff_score` 为止，统计得到实际入围人数 `actual_count`；
   - 第一行输出分数线和实际入围人数；
   - 随后逐行输出前 `actual_count` 名选手的报名号与成绩。

##### 复杂度评估：
- **时间复杂度**：数据规模 $n \le 5000$，$n \log n \approx 5000 \times 13 \approx 6.5 \times 10^4$，在常规 CPU 上耗时不超过 $2\text{ms}$，远低于洛谷 $1.0\text{s}$ 的时间限制；
- **空间复杂度**：仅需存储 $5000$ 个选手信息的数组，内存占用不到 $100\text{KB}$，极其轻量。

---

#### 4. 常见失分点与避坑提示

1. **浮点运算精度陷阱**：
   - 避免使用 `double target = m * 1.5;` 之后强转。推荐采用整数乘除运算 `m * 3 / 2`，数学上完全等价且 $100\%$ 保证无浮点截断误差；
2. **下标偏移（0-based vs 1-based）**：
   - 若数组从下标 $0$ 开始存储，第 $k$ 名选手的下标是 $k - 1$。初学者切忌误写为 `a[target_rank]`，导致多后移了一位；
3. **重分选手的统计边界**：
   - 很多同学误以为只要截取前 $m \times 150\%$ 名即可，忽略了“成绩等于分数线的所有选手全部进入面试”的规则。必须在排序后根据分数线扫描统计完整的入围人数；
4. **同分选手的次要规则**：
   - 输出必须保证同分情况下报名号小的在前，比较函数中必须包含 `a.id < b.id` 的仲裁逻辑。

### 完整参考代码 (C++11)

```cpp
/**
 * Problem: luogu-P1068 [NOIP2009 普及组] 分数线划定
 * Algorithm: 结构体多关键字排序与比例截断 (Multi-key Struct Sorting)
 * Standard: C++11 (CCF GESP 四级 / CSP-J 官方规范)
 * Author: OneCoder
 */

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 选手信息结构体
struct Candidate {
    int id;    // 报名号 (1000 ~ 9999)
    int score; // 笔试成绩 (1 ~ 100)
};

// 自定义多关键字比较函数
// 规则 1：成绩从高到低排序（降序）
// 规则 2：成绩相同时，报名号由小到大排序（升序）
bool cmp(const Candidate& a, const Candidate& b) {
    if (a.score != b.score) {
        return a.score > b.score;
    }
    return a.id < b.id;
}

int main() {
    int n, m;
    cin >> n >> m;

    vector<Candidate> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i].id >> a[i].score;
    }

    // 执行多关键字排序
    sort(a.begin(), a.end(), cmp);

    // 划定面试基准名次：m * 150% 向下取整
    int target_rank = m * 3 / 2;

    // 面试分数线为基准名次选手的成绩（下标从 0 开始，第 target_rank 名下标为 target_rank - 1）
    int cutoff_score = a[target_rank - 1].score;

    // 统计实际进入面试的人数（包含所有不低于分数线的重分选手）
    int actual_count = 0;
    while (actual_count < n && a[actual_count].score >= cutoff_score) {
        actual_count++;
    }

    // 第一行输出：面试分数线 实际进入面试的选手数
    cout << cutoff_score << " " << actual_count << "\n";

    // 接下来输出所有入围选手的报名号与笔试成绩
    for (int i = 0; i < actual_count; ++i) {
        cout << a[i].id << " " << a[i].score << "\n";
    }

    return 0;
}
```
